# More Mushrooms v0.8.0 — 작은 야생 군락과 나무 서식 조건

작업일: 2026-10-11. 사용자 승인 범위인 **같은 종의 작은 야생 군락**과 **여섯 종의 나무 주변 발생 조건**을 구현하고 해당 기능 검사를 완료했습니다. 실제 결과와 한계는 [검증 기록](VALIDATION.md)에 정리합니다. 최종 배포·설치 해시 확인은 기능 검사와 구분합니다.

## 작은 군락

새 지도를 처음 생성할 때 기본 게임이 만든 같은 종의 야생 버섯을 **2~5개 규모의 불규칙한 인접 군락**으로 모읍니다. 이미 생성한 식물의 위치를 재배치하는 방식으로 총량·식별자·성장률·나이를 보존합니다. 이 군락 작업 때문에 버섯을 복제하거나 수확물을 더 만들지 않습니다.

이후 기본 게임의 자연 발생으로 새 버섯 한 개가 생길 때는 근처 같은 종의 작은 군락에 빈자리가 있으면 합류할 수 있습니다. 작은 군락은 최대 5개를 목표로 하며 기존 이웃 버섯을 옮기지 않습니다. 적합한 빈자리가 없거나 같은 종이 드물고 수량이 부족하면 단독으로 남을 수 있습니다.

**2~5개는 새 배치의 목표이며, 모든 자연 발생 인접 군락의 최대 크기가 아닙니다.** 기본 게임이 처음부터 크게 이어 놓은 군락은 분해하지 않습니다. 적합한 대체 자리가 전혀 없으면 원래 자리와 수량 보존을 우선하므로 5개를 넘는 인접 군락도 남을 수 있습니다. 같은 종이 이어져 보이는 모든 덩어리를 강제로 최대 5개로 나누는 기능은 아닙니다.

군락은 적합한 야생 흙을 사용합니다. 지붕 아래·재배구역·수경분지와 식물이 설 수 없는 칸은 후보에서 제외합니다. 나무 조건이 있는 종류는 옮길 자리도 해당 조건을 충족해야 합니다.

## 여섯 종의 나무 조건

| 버섯 | 필요한 주변 나무 | 나무 성장률 | 거리 |
|---|---|---:|---:|
| 송이버섯 | 소나무 | 50% 이상 | 1~2칸 |
| 차가버섯 | 자작나무 | 50% 이상 | 1~2칸 |
| 포르치니버섯 | 종류 제한 없는 나무 | 50% 이상 | 1~2칸 |
| 블랙트럼펫버섯 | 종류 제한 없는 나무 | 50% 이상 | 1~2칸 |
| 광대버섯 | 종류 제한 없는 나무 | 50% 이상 | 1~2칸 |
| 마귀광대버섯 | 종류 제한 없는 나무 | 50% 이상 | 1~2칸 |

거리는 **대각선도 한 칸으로 세는 격자 거리(Chebyshev)**입니다. 나무를 중심으로 가로·세로 차이가 각각 최대 2칸인 범위에서 적합한 야생 흙을 찾으며, 나무가 점유한 칸은 제외합니다. 나무에 붙은 별도 사물이나 줄기 위 수확물을 만들지는 않습니다. 차가도 주변 흙에 자라는 기존 버섯 식물로 표현합니다.

필요한 종류와 성장률의 나무가 없으면 해당 버섯의 **새 발생을 차단**합니다. 이 조건은 최초 지도 생성과 이후 자연 발생에 적용합니다. 지도 생성 중 식물을 순회하는 순서에 따라 근처 나무가 아직 만들어지지 않았거나 기준에 못 미치면 선택 기회가 줄어들 수 있습니다. 나무가 많은 지도라도 모든 여섯 종의 발견을 보장하지 않습니다.

이는 림월드에서 확인할 수 있는 나무와 흙을 사용한 게임용 서식 조건입니다. 현실의 균근·기생 관계나 정확한 숙주 범위를 재현한다고 주장하지 않습니다. 위 여섯 종 이외의 나무·그루터기·곤충·목재·최근 비 조건은 추가하지 않습니다.

## 발생량과 기존 생태

v0.6.5에서 승인한 **기본 발생 가중치 50% 감소**, **재배 가능 11종 20% : 야생 전용 35종 80%** 설정은 유지합니다. 기준 계절·계산 방법은 [발생량 조정 문서](WILD-ECOLOGY-v0.6.5.md)에 보존합니다.

작은 군락의 초기 재배치는 생성된 총량을 보존하지만, 앞선 자연 생성의 나무 조건은 여섯 종의 출현 기회를 줄일 수 있습니다. 기본 게임의 야생 식물 선택과 계절·기후·빈자리도 영향을 주므로 실제 버섯 개수가 정확히 절반이거나 두 그룹의 개수가 정확히 20:80이라는 뜻은 아닙니다. 이전 버전의 실제 지도 개수를 이번 버전의 결과로 사용하지 않습니다.

| 기존 기능 | v0.8.0 정책 |
|---|---|
| 고리 군락 | 기존 원·반원 모양의 4~7개 군락 유지. 작은 군락과 별도 |
| 고리·균사 공동 추가 예산 | 지도당 하루 8개 유지 |
| 야생 버섯 상한 | 기존 면적별 상한 유지. 250×250 지도에서 500개는 목표량이 아닌 발생 제한 |
| 균사 재생 | 기존 확률·대기·한 번 재생 제한 유지. 재생 자리에도 종별 나무 조건 적용 |
| 나무 조건 6종의 재생 | 현재 여섯 종 모두 기본 재생 확률 0이므로 이 변경으로 재생을 새로 허용하지 않음 |
| 제철·발광 | 기존 계절 배율과 식물 발광 유지 |

작은 군락은 기본 자연 발생의 배치 방식입니다. 고리·균사 예산을 사용해 모든 군락을 2~5개로 채우거나 빈자리를 매일 보충하는 기능은 아닙니다.

## 기존 저장과 보존 범위

**기존 저장에 이미 있던 버섯은 옮기지 않습니다.** 저장을 불러왔다고 과거 식물을 새 군락으로 정리하거나 강제로 삭제하지 않습니다. 이후 새로 자연 발생하는 버섯부터 나무 조건과 군락 합류를 적용합니다.

재배구역·수경분지·모둠버섯의 11종 동일 확률, 성장일수·수확량·가치·영양·맛 무드·환각·중독·치료·v0.7.0 섭취 설정과 기존 그림·식별자는 유지합니다. 약용 효과·약 제작은 계속 보류하며 감정 시스템은 추가하지 않습니다. 그루터기·숙주·비·목재 규칙, 환경 피해, 채집 의뢰와 원목·배지 재배시설도 이번 범위에서 제외합니다.

이전 README는 [v0.7.0 기록](History/README-v0.7.0.md)에 실행 ZIP 원본 그대로 보존합니다. 버전별 실행·소스 ZIP·해시와 설치 백업을 남기는 기존 절차를 사용하며, 실제 배포·설치 완료는 해당 검사 결과로 확인합니다. GitHub·Steam 창작마당 게시는 이번 작업에 포함하지 않습니다.

## 검증 결과

정적 검사 **3,298개**, v0.7.0 대비 보존 대조 **611개**를 통과했고 정의 생성 반복 실행에서 **292파일이 동일**했습니다. 기존 배포 파일 68개·사용자 설정 48개·사용자 저장 45개도 보존했습니다. 증거는 [정적 검사](TestResults/v0.8.0-static.json), [보존 대조](TestResults/v0.8.0-preservation.json), [반복 생성](TestResults/v0.8.0-idempotence.json)에 기록합니다.

Core + Harmony 한국어 **332개**, 공식 DLC 전체 + Harmony 영어 **337개**의 네이티브 군락·서식·새 저장 복원 검사를 통과했습니다. 증거는 [Core 요약](TestResults/v0.8.0-Core-Korean/summary.json)과 [DLC 요약](TestResults/v0.8.0-DLC-English/summary.json)에 보존합니다.

| 온대림 초기 재배치 | Core 한국어 | 공식 DLC 전체 영어 |
|---|---:|---:|
| 버섯 수, 전 → 후 | 179 → 179 | 168 → 168 |
| 2개 군락 | 17 | 18 |
| 불규칙한 3~5개 군락 | 37 | 34 |
| 단독 버섯 | 9 | 6 |
| 5개 초과 / 3개 이상 직선 군락 | 0 / 0 | 0 / 0 |

DLC의 250×250 지도는 전체 식물 26,865개를 보존했고 버섯 110개가 이동했습니다. 이후 발생·서식의 통제 시험에서는 기본 야생 발생기를 사용했으며 최종 DLC 집계는 버섯 발생 호출 339회·합류 재배치 20회입니다. 이 수치는 시험 사례의 합계이며 장기 자연 발생 빈도가 아닙니다. 두 지도에서 5개 초과 군락이 없었다고 다른 지도에서도 최대 5개를 보장하지 않습니다.

Core 저장 시험은 균사 예약·사용 예산이 0인 상태였습니다. DLC 시험에서는 실제 선택된 버섯의 재생 세대 1·재생 소모 상태·미래 예약 1개·사용 예산 1개를 만들고 저장/불러오기 뒤 모든 버섯의 ID·위치·성장·나이·체력·재배·재생 상태와 균사 예약·난수·다음 검사 시각·예산의 일치를 확인했습니다. 불러오기 때 초기 재배치는 재실행하지 않았습니다. 재생 준비의 확률 우회·통제 시간 진행은 시험에만 한정하며 자연 재생 확률이나 전체 월드 장기 경과를 검증한 것이 아닙니다.

**저장 검증은 새 v0.8.0 격리 저장의 왕복 복원입니다. 실제 v0.7.0 저장 불러오기는 이번에 실행하지 않았으며 사용자 저장 45개의 해시 보존과 구분합니다.**

전체 사용자 모드 조합·장시간 정착지 플레이·모든 생물군계와 시드의 발생 분포는 새로 검사하지 않았습니다. 이전 버전의 통과 수와 지도 수를 이번 기능을 재실행한 증거로 간주하지 않습니다.
