# v0.9.2 — RimWorld 1.6·1.7 호환

기록일: 2026-10-15. v0.9.2는 지원 버전에 **1.7**을 추가하는 호환성 업데이트입니다. 확인 대상은 **RimWorld 1.7.4977 rev1248**입니다. 1.7은 현재 unstable 베타이며 일반 배포 버전은 1.6입니다. [Ludeon 공식 발표](https://ludeon.com/blog/2026/10/announcing-the-waylith-engine-and-update-1-7/)는 새 Waylith 엔진이 대부분의 기존 모드를 지원한다고 안내하지만 개별 모드의 실행 검사를 대신하지 않습니다.

## 유지하는 게임 내용

- 버섯 46종과 기존 Def·텍스처·번역·packageId `izzypizzy.rimmushrooms`.
- 재배 가능한 식용 11종과 모둠버섯의 기본 성장기간 6일. 별도 야생 팽이 5일·송이 12일.
- 수확량·식물 기술·가치·맛 무드·향정신성·중독·치료·식용 제한 설정.
- 야생 발생 가중치, 2~5개 작은 군락, 제철·발광·고리·균사 재생, 숙주·목재·비·종별 서식 조건.

약용버섯 약효·버섯 생약 제작 개발은 중단 상태를 유지합니다. 버섯 전용 요리 시스템도 추가하지 않습니다. 미배포 약용 그림·설계 초안은 로컬에 보존하고 공개 소스 패키지에서 제외합니다.

## 기존 생산 DLL을 사용하는 이유와 재빌드 방법

생산 어셈블리는 기존 `Assemblies/RimMushrooms.dll` 하나이며 .NET Framework 4.7.2로 빌드된 v0.9.1 바이너리를 그대로 사용합니다. 1.6은 기존 실행 방식으로, 1.7은 Waylith의 기존 모드 호환 계층을 통해 로드합니다. 별도 1.7 생산 DLL이나 새 생산 소스 코드는 추가하지 않습니다.

v0.9.1 보관 소스 ZIP과 생산 C# 소스 **13개**, `MoreMushrooms.csproj`를 바이트 단위로 대조하고 생산 DLL 해시가 보관 manifest와 일치함을 확인했습니다.

```text
RimMushrooms.dll SHA-256
9e5a178a3e348b021fae35c81962368e51bfc643cc08e96fdefb5f2bcb2e0cf5
```

이 업데이트에서는 **생산 DLL을 새로 컴파일했다고 주장하지 않습니다**. 보존한 바이너리를 검증하는 배포 경로는 다음과 같습니다.

```powershell
.\Scripts\Release.ps1 -Install -ReuseVerifiedBinary
```

`Scripts/verify_reused_binary.py --previous-version 0.9.1`이 생산 소스 목록·내용·프로젝트·DLL을 검사하고 차이가 있으면 배포를 중단합니다. 생산 소스나 빌드 입력을 바꿨다면 이 옵션을 사용할 수 없습니다. 기존 `MoreMushrooms.csproj`를 재빌드하려면 RimWorld 1.6 설치와 해당 어셈블리를 참조해야 합니다. 1.7 설치의 어셈블리로 기존 net472 프로젝트를 빌드할 수 있다는 뜻은 아닙니다.

Core는 예상 모드 4개, DLC는 9개를 실제 로드한 격리 프로필입니다. [Core 검사 보고서](TestResults/v0.9.2-Core-Korean-smoke.txt)·[DLC 검사 보고서](TestResults/v0.9.2-DLC-English-smoke.txt)·[실행 요약](TestResults/v0.9.2-native-summary.json)에 최종 결과를 남깁니다. 새 1.7 시험 저장의 왕복 복원과 별도로, 1.6에서 만든 격리 v0.6.5 시험 저장을 1.7에서 불러와 유효 식물 137개의 ID·성장·생태 플래그와 음식 정책 6개를 원본 XML과 대조했습니다. 원본에 요리 작업이 0개이므로 실제 이전 요리 작업 복원까지 검사한 결과는 아닙니다. 원본의 기존 사물 겹침 1건을 확인한 허용 사례와 설명되지 않은 식물 누락을 구별합니다.

1.7 검사 하네스는 개발 검사용이며 배포 실행 ZIP에 포함하지 않습니다. 초기 시도의 하네스 실패와 최종 성공, Epic/Rockstar 오버레이 JSON 경로 누락 환경 진단은 [검증 기록](VALIDATION.md)에 구분합니다. 최종 두 프로필은 합계 **13,235개** 검사와 `RESULT PASS`를 확인했고 Verse 오류·예외가 없었습니다. Windows 설정은 변경하지 않았습니다. 실제 화면은 로딩 프레임만 관찰했고 전체 화면 가독성 검수는 수행하지 않았습니다. 저장 파일 해시 보존과 실제 게임 왕복 복원은 별도 결과이며 베타 엔진의 이후 변경까지 호환성을 보장하지 않습니다.

## 게시 순서

이번 사용자는 검증 뒤 **Steam 창작마당 → GitHub → 모두 완료한 뒤 PC 종료**를 명시적으로 요청했습니다. 기존 Steam 항목 `3813323629`를 갱신하며 별도 항목을 만들지 않습니다. Steam 항목의 기존 제목·설명·공개 상태를 유지하고 지원 태그와 콘텐츠·변경 안내를 갱신합니다.

이 문서는 게시 전 준비 기록입니다. 실제 게시 성공은 Steam 제출 결과와 서버 재조회, GitHub 원격 커밋·태그·릴리스 자산을 확인한 뒤 별도 기록합니다. 게시가 끝나기 전에 PC를 종료하지 않습니다.
