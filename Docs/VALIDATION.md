# v0.1.2 검증 기록

검증일: 2026-10-03. RimWorld 1.6.4871 rev591.

- 정적 검사 **179개 통과**: 세 등급(각 3종) +3/+5/+7과 송이 +10, 지속시간 6시간, 생성 정의·번역·기존 이미지 확인.
- Core + 전체 5개 DLC + 한국어 격리 게임 검사 **492개 통과**. 증거: `Docs/TestResults/v0.1.2-AllDLC-Korean.txt`.
- 각 등급 안에서 서로 다른 버섯을 이어 먹었을 때 효과 하나만 유지하고, 마지막 품종의 이름으로 교체하며, 6시간으로 갱신되는 것을 실제 섭취 API로 확인.
- 기존 10종의 생식·요리, 혼합 재료, 높은 효과 우선, 약한 효과로 지속시간 연장 방지, 만료 및 저장/불러오기 검사 통과.
- 실행 로그에서 이 모드의 XML/설정/번역/섭취 예외 오류 없음.
- v0.1.1 소스 ZIP과 비교해 무드 수치와 버전 외 재배·수확·가격·보관 수치 및 실행 C# 코드가 동일함을 확인. Core 전용 실행은 이번 수치 조정에서 반복하지 않았으며, 동일 코드의 v0.1.1 Core 검증 기록을 아래에 유지.
- 전체 Workshop 모드 조합은 별도 검증하지 않음. 이번 실행도 섭취 API와 만료 경계 검증이며 실제 여섯 시간을 기다리는 방식은 아님.

배포: `Releases/v0.1.2/`에 실행 ZIP·소스 ZIP·SHA-256 목록. 이전 버전과 설치 백업 유지.

# v0.1.1 검증 기록

검증일: 2026-10-03. RimWorld 1.6.4871 rev591, 설치된 게임 DLL로 빌드.

| 검사 | 결과 | 증거 |
|---|---|---|
| 정적 XML·버전·번역·무드 링크·이미지 | 179개 통과 | `Tests/validate_assets.py` |
| Core + 모드, 영어, 무드 중심 실행 검사 | 468개 통과 | `Docs/TestResults/v0.1.1-Core-English.txt` |
| Core + 5개 DLC + 모드, 한국어, 무드 중심 실행 검사 | 468개 통과 | `Docs/TestResults/v0.1.1-AllDLC-Korean.txt` |

- 식재료 10종 각각에 대해 실제 게임의 `Thing.Ingested()`로 생식 및 버섯 재료를 등록한 좋은 식사를 섭취하여 정확한 무드 기억과 수치를 확인했습니다.
- 10종이 서로 다른 +1~+10을 제공하며 15,000틱(6시간) 동안 유지됩니다. 14,999틱에서 유지, 15,000틱에서 만료, 다음 기본 기억 처리 주기에 제거되는 것을 확인했습니다.
- 혼합 재료 순서를 뒤집어도 가장 높은 효과 하나만 적용됩니다. 같은 종류 재섭취는 시간 갱신, 높은 종류는 교체, 낮은 종류는 기존 높은 효과의 시간을 연장하지 않습니다.
- 만료된 높은 효과가 새로운 낮은 효과를 막지 않습니다. 기본 영양버섯과 버섯 없는 요리에는 새 보너스가 없습니다.
- 기존 생식/요리 등급/사상에서 생성되는 기억은 유지됩니다. 무드 욕구가 없는 동물의 섭취도 오류 없이 완료됐습니다.
- 남은 시간이 있는 송이 효과를 저장·불러오기로 복원하고, +10 및 경과 시간 5,000틱 유지, 영어·한국어 표시와 이후 만료를 확인했습니다.
- 기존 그림 52장의 원본 해시, 수량별 그래픽, 분할·합치기·운반 및 저장 복원 검사도 함께 통과했습니다.
- 두 실행 로그에서 이 모드의 XML/설정/번역/섭취 예외 오류가 발견되지 않았습니다. 시험 도우미는 배포하지 않습니다.

이번 `-MoodOnly` 검사는 격리 프로필에서 게임의 실제 섭취 API와 재료 기록을 사용합니다. 주민이 직접 요리하고 식탁까지 이동하는 작업 전체나 실제 6시간을 기다리는 검사는 아니며, 만료 경계와 기본 기억 처리 주기를 직접 검사했습니다. 파종/수확 동작과 재배 수치는 변경하지 않았으며, 아래 v0.1.0의 실제 작업 검증 기록을 유지합니다. 사용자의 전체 Workshop 모드 조합 및 음식 선택 AI, 다른 가공품 모드와의 조합은 별도 검증하지 않았습니다. 버섯 보너스는 음식에 남아 있는 기본 게임의 재료 기록을 따릅니다.

배포: `Releases/v0.1.1/`의 실행 ZIP·소스 ZIP·SHA-256 목록. 기존 v0.1.0 배포본과 이전 설치 백업을 유지합니다.

# v0.1.0 검증 기록

검증일: 2026-10-03, 한국 시간.

## 환경

- 실제 실행 로그: **RimWorld 1.6.4871 rev591**, Unity 2022.3.35f1.
- 설치 폴더의 `Version.txt`는 rev590이지만, 검증 기준은 실제 실행 버전입니다.
- 설치된 게임의 Assembly-CSharp.dll 및 Unity 참조로 .NET Framework 4.7.2 빌드 성공.
- 플레이어의 개인 설정/저장 대신 `Tests/Runtime/`의 별도 프로필을 사용했습니다.

## 통과한 검사

| 검사 | 결과 | 증거 |
|---|---|---|
| 정적 파일·XML·그림 검사 | 144개 통과 | `Tests/validate_assets.py` |
| Core + 모드, 영어 | 330개 통과 | `Docs/TestResults/Core-English.txt` |
| Core + 5개 DLC + 모드, 한국어 | 332개 통과 | `Docs/TestResults/AllDLC-Korean.txt` |

- 고유 식물 11개, 식재료 10개, 재배 가능한 종류 정확히 9개.

- 식물의 A/B 그래픽, 영양버섯식 maxMeshCount/visualSizeRange, 성숙 수확량, 빛 0%/100% 성장 계수 확인.
- 팽이 재배형은 야생 후보에서 제외. 별도 야생형 및 다른 종류는 지정 생물군계 후보에 등록됨.
- 각 재배 9종에 대해 실제 주민의 파종 작업 완료 및 실제 `Plant.TickLong()` 성장 진행 확인.

- 모든 식재료의 균류 분류, 일반 간단한 식사 재료 필터, 부패 컴포넌트 확인.
- 각 식재료 1/25/26/50/51/75개의 실제 재질 선택 확인.
- 실제 게임 API로 75→50+25 분할, 50+25 합치기, 운반 컨테이너로 25개 들기, 내려놓고 합치기 확인.
- 시험 저장 생성 후 다시 불러와 성장 시안 식물 33개 이상과 수량별 식재료 그래픽 복원 확인.
- 성공 실행 로그에 이 모드의 XML 참조/설정/텍스처/예외 오류 없음.

## 시험 조건과 범위

자동 시험은 준비한 흙 구역에서 재배 가능한 주민에게 작업을 명령합니다. 각 종의 정상 성장 틱을 확인한 후 성숙도를 100%로 올려 수확합니다. 성공적인 수확 경로를 반복 검증하기 위해 시험 중에만 기본 수확 실패 확률을 끄고, 수확 직후 원래 값으로 돌려놓습니다. 설치되는 모드의 수확 실패 규칙은 기본 게임 그대로입니다. 6~12 growDays 전체를 실시간으로 기다린 장기 밸런스 검증은 아닙니다.

운반 검사는 실제 carryTracker의 집기·내리기 경로를 사용하지만, 장거리 운반 AI나 외부 창고 모드 전체를 검증한 것은 아닙니다. 야생 출현은 엔진의 생물군계 후보·가중치 연결을 확인했으며, 여러 시드의 장기 분포를 통계적으로 검증하지는 않았습니다.

Steam 외부의 격리 실행에서 SteamAPI 초기화 경고가 있었으나 Core 및 DLC 콘텐츠는 실제로 로드되었습니다. DLC 시험 저장을 불러올 때 게임의 숨겨진 장례 의례를 보충하는 기본 게임 메시지가 기록됐습니다. 이를 버섯 모드 오류로 숨기거나 수정하지 않았습니다.

## 추가 플레이 검토

- 게임 화면에서 여러 줌 배율·설원·밝고 어두운 지면의 가독성.
- 사용자가 쓰는 전체 Workshop 모드 조합, 특히 저장·스택 변경 모드.
- 초안 성장/수확/판매 가치와 야생 발생 빈도의 장기 밸런스.

자동 실행의 기본 ScreenCapture 출력은 검게 나왔습니다. 별도의 렌더 텍스처로 캡처하는 방식도 지형·식물 화면을 정상적으로 담지 못해, 이 파일들을 시각 검증의 증거로 사용하지 않습니다. PNG와 실제 재질 선택·게임 로직은 확인했지만 **완성된 게임 화면의 육안 검토는 아직 미완료**입니다. 실패한 캡처 코드는 최종 시험 도우미에서 제거했습니다.

## 배포

런타임 폴더는 About, Assemblies, Defs, Languages, Textures, Credits와 사용 안내만 포함합니다. 게임 참조 DLL, 시험용 DLL 및 시험용 설정은 배포하지 않습니다. 테스트 도우미는 검증 후 Mods 밖으로 옮깁니다.

설치 스크립트는 기존 설치를 프로젝트의 Backups에 보존하고 새 설치 파일의 SHA-256을 대조합니다. 실행 ZIP과 소스 ZIP은 Releases/v0.1.0에 별도로 보관하며 같은 버전을 덮어쓰지 않습니다.
