# v0.4.0 검증 기록

검증일: 2026-10-05~06. 식용 버섯 10종을 유지하면서 야생 독버섯 5종과 중독·치료·회복을 추가.

- 설치된 RimWorld 1.6.4871 rev591의 참조 DLL로 .NET Framework 4.7.2 빌드 성공. Harmony나 추가 프레임워크를 사용하지 않습니다.
- XML·Def·번역·게임 수치·원본 그림 검사가 **644개 통과**했습니다. XML 22개, 고유 정의 48개, 게임 텍스처 78장입니다. 독버섯 식물 5개·수확물 5개·중독 5개·원료 분류 1개를 추가했습니다.
- 2026-10-05 인계 파일 85개의 크기와 SHA-256 및 승인된 게임 PNG 25장의 해시를 확인하고 원본을 보존했습니다. 식물 A/B와 수확물 적음/중간/가득 그림을 바이트 수정 없이 사용합니다.
- 이전 v0.3.3 ZIP 두 개의 SHA-256, 기존 배포 파일 70개의 바이트 일치, 버전 외 식용 버섯 밸런스의 완전 일치를 확인했습니다. 증거: `Docs/TestResults/v0.4.0-Static-Comparison.txt`.

| 검사 | 결과 | 증거 |
|---|---|---|
| Core + 모드, 영어, 전체 실행·새 저장·이전 저장 | 3,013개 통과 | `Docs/TestResults/v0.4.0-Core-English.txt` |
| Core + 5개 DLC + 모드, 한국어, 무드 중심 실행·새 저장·이전 저장 | 2,134개 통과 | `Docs/TestResults/v0.4.0-AllDLC-Korean.txt` |

두 실행 모두 독버섯 검사가 각각 **413개 통과**했습니다.

- 5종의 실제 섭취·잠복기 경계·증상·회복, 자동 음식 선택과 기본 요리 제외, 야생 전용 및 작물 목록 제외를 확인했습니다. 식물 A/B와 수확물 6개 수량 경계의 실제 게임 재질을 확인했습니다.
- 두 치명종은 건강한 단일 노출 환자의 중증도를 최대로 올린 시험에서도 첫 증상 뒤 24시간 전에 죽지 않았습니다. 유예 뒤 위중 상태와 자연 방치 경과에서는 기본 사망 처리가 발생했습니다.
- 건강하고 의료 작업이 가능한 식물 기술과 별개의 의료 기술 20 의사를 사용하여 실제 `TendUtility.DoTend`를 검사했습니다. 일반 약품 반복 치료로 두 치명종이 안정화·완치되며 한 번의 치료로 끝나지 않습니다. 같은 틱의 진료 반복 차단과 6시간 직전/정각 재치료 경계를 확인했습니다.
- 동일 의사와 같은 난수에서 일반 약품이 약초보다 높은 실제 치료 품질과 누적 효과를 제공했고 무약품 진료도 도움이 됐습니다. 치료 품질의 기본 게임 난수와 약품 상한을 유지합니다.
- 광대버섯 4회 섭취로 의식 0.2와 쓰러짐이 발생하고, 살아서 회복하며 중독이 제거되는 것을 확인했습니다. 반복 노출은 중독 하나·최대 4회분·제한된 회복 연장으로 유지됩니다.
- 5종의 잠복·진행·치료·회복 사례를 저장한 뒤 종류·원인·중증도·단계 및 모든 진행 필드와 기본 치료 컴포넌트가 같은 값으로 복원되고 다음 건강 틱이 정상 처리됐습니다. 기존 식용 버섯 무드와 이전 식물 저장의 ID·위치·성장·나이·체력도 복원했습니다.
- 성공 로그에서 모드의 XML·설정·번역·중독 예외 및 저장 참조 오류가 없었습니다. 로그는 같은 TestResults 폴더의 `v0.4.0-*-Player.log`에 보관합니다. Steam 외부 실행 경고와 기본 게임의 간헐적 간헐천 소리 경고, DLC 이전 저장의 숨겨진 장례 의례 보충 메시지는 별개로 남깁니다.
- 개인 `ModsConfig.xml`의 시험 전후 SHA-256이 동일합니다. 도우미 모드는 검사 후 Mods 밖으로 보관했고 배포본에 포함하지 않습니다.

검사 조건은 개인 프로필과 분리한 Core/영어 및 Core+5개 DLC/한국어입니다. 기존 실제 파종·수확·모둠·수경·광량·무드 검사를 유지하고, 독버섯의 명시 섭취 허용 조건·수량 계산·섭취 API, 기본 음식 선택·요리 필터, 치료 API, 건강 진행, 저장/불러오기를 추가 검사했습니다. 여러 날의 중독 경과는 격리 폰의 게임 시간을 전진시키며 실제 `HealthTickInterval`로 확인했습니다. 테스트 후 원래 게임 시간을 복원합니다. 한국어/DLC 시험의 기상과 무작위 사건은 도우미에서 통제하여 번개 화재가 파종을 선점하지 않도록 했으며, 배포 모드의 기상·사건 규칙은 바꾸지 않았습니다. 해당 `-MoodOnly` 실행만 개별 9종의 지상 작업 반복을 생략하며 실제 수경 작업과 모든 독버섯 검사는 유지합니다.

중독 경과 검증은 실시간으로 8일을 기다리는 장기 플레이나 의사가 침대까지 걸어가 치료하는 작업 전체 검증과 구분합니다. 숨긴 격리 실행에서 Unity `OnGUI`가 호출되지 않아 우클릭 메뉴의 실제 렌더링·클릭은 검증하지 않았습니다. 같은 메뉴가 사용하는 섭취 허용 조건과 기본 수량 계산·섭취 작업 생성 경로를 확인합니다. 구토 주기는 기본 건강 단계에 연결되지만 확률에 따른 장기 구토 횟수, 여러 맵의 자연 분포, 다른 모드와의 전체 조합 및 작은 게임 화면에서의 그림 가독성은 별도 확인하지 않았습니다. 화경버섯의 심한 장 출혈 증상은 통증·쇠약으로 표현하며 실제 혈액 손실이나 영구 장기 손상은 추가하지 않습니다.

배포는 `Releases/v0.4.0/`의 실행 ZIP·소스 ZIP·SHA-256 목록이며 이전 버전과 설치 백업을 보존합니다. 업데이트에서 기존 창작마당 게시 ID를 유지합니다. Steam 창작마당 업로드는 이 작업에 포함하지 않습니다.

# v0.3.3 검증 기록

검증일: 2026-10-04. 게임 모드 목록 설명을 사용자 지정 한 문장으로 교체.

- `About/About.xml`의 설명은 정확히 `재배가능한 10종류의 버섯을 추가합니다.` 한 문장입니다. 기존 영문·국문 소개와 업데이트 내역은 설명란에서 모두 제거했습니다.
- About와 Balance, README의 버전을 0.3.3으로 맞췄습니다. 설명 이외의 이름·저자·packageId·지원 게임 버전은 v0.3.2와 같습니다.
- 기존 정적 XML·번역·버전·텍스처·표지 검사가 **218개 통과**했습니다. v0.3.2 실행 ZIP·소스 ZIP의 SHA-256을 확인하고 설명·문서 이외의 배포 파일 71개와 C# 소스 5개, 버전 이외의 밸런스 수치가 모두 같음을 확인했습니다.
- 정의 생성기는 About.xml을 수정하지 않으므로 재생성 시에도 짧은 설명을 유지합니다. 게임 동작 변경이 없어 게임 실행 검사는 반복하지 않았습니다. 실제 모드 목록 화면은 게임을 다시 시작한 뒤 새 설명을 읽습니다.

배포: `Releases/v0.3.3/`에 실행 ZIP·소스 ZIP·SHA-256 목록을 보관하고, 게임 종료 확인 후 실제 Mods 폴더에 설치합니다. 이전 버전과 설치 백업을 보존합니다.

# v0.3.2 검증 기록

검증일: 2026-10-04. 사용자가 확정한 랫킨 표지 v1 적용.

- `About/Preview.png`는 보존한 `Art/Covers/v0.3.1/MoreMushrooms-cover-v1.jpg`와 바이트 단위로 일치합니다. 1672×941 RGB, 480,600바이트이며 PNG 원본·JPEG export·생성 기록은 보존합니다. 이미지 디코드와 표지 그림을 직접 확인했습니다.
- 설치된 기본 게임의 `ModMetaData.PreviewImagePath`가 `About/Preview.png`를 사용하고, `PreviewImage`가 바이트를 `Texture2D.LoadImage`로 디코드하는 것을 확인했습니다. 같은 경로가 `GetWorkshopPreviewImagePath`를 통해 창작마당 업로드에 전달됩니다.
- 파일명은 기본 게임이 고정한 `.png`이며 실제 내용은 지원되는 JPEG입니다. Unity의 `ImageConversion.LoadImage`는 바이트 내용으로 PNG/JPEG를 디코드합니다. 게임의 Workshop 코드는 파일 존재만 확인한 뒤 `SteamUGC.SetItemPreview`에 경로를 전달합니다. 참고: https://docs.unity3d.com/ScriptReference/ImageConversion.LoadImage.html 및 https://partner.steamgames.com/doc/api/ISteamUGC#SetItemPreview .
- 생성기가 해당 표지를 다시 복사하도록 변경했습니다. 생성기 실행 후 정적 정의·번역·그림·표지 경로/해시/용량 검사가 **218개 통과**했습니다. 기존 버섯 텍스처 53장과 재배·무드·식별자·C# 실행 코드는 유지됩니다.
- 이전 버전과의 상세 정적 대조 결과는 `Docs/TestResults/v0.3.2-Static-Comparison.txt`에 보관합니다. 이미지와 연결만 변경하므로 전체 게임 파종·수확 검사는 이번 표지 적용에서 반복하지 않았습니다. 이전 실행 검증은 아래에 유지합니다.

실제 게임의 모드 목록 화면 검수와 Steam 발행은 실행하지 않았습니다. 이번 작업은 업로드용 표지 파일의 로컬 설정이며 창작마당 게시 자체를 수행하지 않습니다.

배포: `Releases/v0.3.2/`에 실행 ZIP·소스 ZIP·SHA-256 목록. 게임 종료 확인 후 실제 Mods 폴더에 설치하고 이전 설치를 Mods 밖에 백업합니다. 모든 이전 버전은 보존합니다.

## 시험 조건과 범위

자동 시험은 준비한 흙 구역에서 재배 가능한 주민에게 작업을 명령합니다. 각 종의 정상 성장 틱을 확인한 후 성숙도를 100%로 올려 수확합니다. 성공적인 수확 경로를 반복 검증하기 위해 시험 중에만 기본 수확 실패 확률을 끄고, 수확 직후 원래 값으로 돌려놓습니다. 설치되는 모드의 수확 실패 규칙은 기본 게임 그대로입니다. 6~12 growDays 전체를 실시간으로 기다린 장기 밸런스 검증은 아닙니다.

운반 검사는 실제 carryTracker의 집기·내리기 경로를 사용하지만, 장거리 운반 AI나 외부 창고 모드 전체를 검증한 것은 아닙니다. 야생 출현은 엔진의 생물군계 후보·가중치 연결을 확인했으며, 여러 시드의 장기 분포를 통계적으로 검증하지는 않았습니다.

Steam 외부의 격리 실행에서 SteamAPI 초기화 경고가 있었으나 Core 및 DLC 콘텐츠는 실제로 로드되었습니다. DLC 시험 저장을 불러올 때 게임의 숨겨진 장례 의례를 보충하는 기본 게임 메시지가 기록됐습니다. 이를 버섯 모드 오류로 숨기거나 수정하지 않았습니다.
