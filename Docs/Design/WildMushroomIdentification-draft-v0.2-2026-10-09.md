# More Mushrooms 야생버섯 시스템 초안

감정 기능은 기획에서 제외한다. 야생버섯의 표시와 요리 및 섭취 후 정체 공개는 후속 기능의 기획 방향으로 남아 있으며, 현재 설치된 모드는 독버섯 5종과 직접 섭취에 따른 중독 및 일반 의료 치료까지 구현한 v0.4.0이다.

| 변경일 | 2026-10-09 |
| 현재 개발 원본과 설치 버전 | v0.4.0 |
| 변경 내용 | 감정 기능 취소와 현재 구현 상태 정리 |

## 감정 기능 취소

버섯과 완성된 식사의 감정 버튼, 감정 작업 지정, 일괄 감정, 식물 기술에 따른 감정 속도, 감정 시간과 성공률을 기획에서 삭제한다. 감정 예약에 따른 섭취 차단, 감정 완료 알림과 감정 결과로 이름 및 그림을 바꾸는 경로도 제외한다.

감정 기능은 기존 초안에만 있었고 실제 게임에는 구현되지 않았다. 실행 코드에서 제거할 감정 기능은 없다. 이전 초안 v0.1은 과거 기획 기록으로 보존하며, 현재 기획은 이 v0.2를 기준으로 한다.

## 유지하는 기획 방향

- 새로운 야생 버섯은 야생버섯이라는 공통 이름과 그림으로 표시하고, 실제 종류는 생성 시 결정해 저장한다.
- 기존 자연 생성 생물군계와 종류별 가중치를 유지한다. 재배한 식용 버섯은 기존 이름과 그림을 사용한다.
- 미확인 버섯을 일반 요리에 사용할 수 있게 하며, 사용 허용 설정과 완성된 식사의 섭취 규칙을 연결한다.
- 요리 후에도 독성을 유지하고, 식사에 실제로 들어간 종류와 원료량을 기록한다.
- 중독 증상이 나타나면 원인이 된 독버섯과 출처를 확인하고, 해당 출처의 남은 원료와 식사의 추가 자동 섭취를 중단한다.
- 중독 치료는 기존 의사, 침대, 약품을 사용한다. 기존 식용 버섯의 성장과 무드 수치는 유지한다.

이 방향은 아직 게임 기능으로 구현되지 않았다. 감정을 통한 사전 선별이 사라졌으므로, 식용 버섯의 정체를 언제 공개할지와 다음 채집에서 어떻게 선별할지는 후속 초안에서 정할 연결 규칙이다. 감정 취소만으로 조리 시 자동 공개나 섭취 직후 모든 종류 공개를 추가 확정한 것은 아니다.

현재 독버섯은 처음부터 실제 이름과 그림이 보이고 설명에도 유독성이 적혀 있다. 자동 섭취와 일반 요리에서는 제외되며, 플레이어가 직접 먹도록 지시하면 중독된다. 원료를 먹을 때의 중독 처리는 있지만, 완성된 식사의 재료를 추적해 독성을 적용하는 처리는 없다. 잠복 중 중독 정보를 숨기는 기능도 아직 적용하지 않았다.

## 버전과 확인 기준

개발 원본과 RimWorld Mods 폴더의 About.xml은 모두 v0.4.0이며 두 위치의 RimMushrooms.dll SHA-256이 일치한다. 실행 소스와 정의에서 위 기능을 확인했다. v0.4.0의 실행 ZIP, 소스 ZIP과 manifest는 Releases/v0.4.0에 보관되어 있다.

기존 실행 검증 기록은 Docs/VALIDATION.md와 Docs/TestResults에 있다. 이번 변경은 기획 문서만 추가하며, 기존 게임 기능의 버전은 v0.4.0이다.

- v0.1 2026-10-06: 야생버섯 공통 표시와 감정 및 미확인 요리와 발병 후 공개를 기획했다. 감정 관련 내용은 v0.2에서 취소했다.
