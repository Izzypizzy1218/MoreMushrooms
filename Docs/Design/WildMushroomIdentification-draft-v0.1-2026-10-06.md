# More Mushrooms 야생버섯 감정 시스템 초안

야생버섯을 채집한 뒤 감정해서 먹을지, 정체를 모른 채 요리할지 선택하는 기능이다. 식용 버섯은 식량과 기존 무드 보너스를 제공하고, 독버섯은 야생 채집에서 주의해야 할 대상으로 역할을 갖는다.

## 적용 범위

More Mushrooms의 야생 식용 버섯 10종과 독버섯 5종을 대상으로 한다. 각 생물군계에서 이미 자연 생성되던 종류와 출현 가중치를 유지하고, 새로 생성되는 야생 개체에 미확인 상태를 붙인다. 15종을 같은 확률로 새로 뽑지 않으며, 송이버섯의 희귀성과 생물군계 제한도 유지한다. 가중치는 실제 출현 퍼센트가 아니다.

재배구역과 수경재배기에서 심은 식용 버섯 9종은 기존처럼 이름과 그림이 보인다. 모둠버섯의 9종 무작위 파종도 유지한다. 자연 생성되는 팽이는 황갈색 야생 팽이이며, 흰 재배 팽이와 구분한다. 송이버섯과 독버섯은 계속 야생 채집 전용이다.

바닐라 영양버섯과 다른 모드의 버섯은 이번 초안의 대상에 포함하지 않는다. 기존 식용 버섯의 성장일수, 수확량, 가격, 무드 수치는 유지한다.

## 야생버섯의 표시와 정체

새 야생 식물이 생성될 때 실제 종류를 정하고 저장한다. 감정하거나 저장을 다시 불러올 때 종류를 다시 뽑지 않는다.

| 상태 | 식물 표시 | 수확물 표시 | 알 수 있는 정보 |
| --- | --- | --- | --- |
| 미확인 | 야생버섯 군락과 공통 그림 | 야생버섯과 공통 그림 | 아직 종류와 식용 여부를 모름 |
| 감정 완료 | 실제 버섯 이름과 기존 그림 | 실제 버섯 이름과 기존 그림 | 종류와 식용 또는 유독 여부 |
| 중독으로 확인 | 원인 군락이 남아 있다면 실제 이름과 그림 | 같은 출처의 남은 수확물에 실제 이름과 그림 | 중독을 일으킨 종류와 해당 출처의 위험성 |

하나의 야생 식물에서 나온 수확물은 하나의 채집 묶음으로 취급한다. 더미를 나눠 운반하거나 식사 재료로 써도 출처를 유지한다. 같은 식물이 다시 수확 가능한 상태로 자라면 종류와 이미 확인한 결과를 유지한다.

감정 결과는 해당 식물과 그 식물에서 나온 수확물에만 공유한다. 표고버섯 한 묶음을 감정했다고 맵 전체의 미확인 표고버섯이 자동으로 밝혀지지는 않는다.

미확인 상태에서는 이름, 그림, 정보창, 재료 목록, 무드 이름을 통해 실제 종류가 먼저 노출되지 않도록 한다. 가격이나 영양량으로 유독 여부가 바로 드러나는 것도 피한다. 개발자모드에서는 검증을 위해 실제 종류와 출처를 확인할 수 있게 한다.

## 감정 작업

바닥에 놓인 야생버섯을 선택하고 감정 작업을 지정한다. 여러 더미를 한꺼번에 지정할 수 있으며, 식물 작업을 맡은 정착민이 수행한다. 감정을 위해 별도 연구나 전용 건물은 요구하지 않는 안으로 시작한다.

미확인 버섯이 들어간 완성된 식사에도 감정을 지정할 수 있다. 식사에 남아 있는 미확인 출처를 각각 확인하며, 원료가 모두 요리되어 사라졌어도 감정할 수 있다. 감정 예약이 된 식사는 작업이 끝나거나 예약을 취소할 때까지 자동 섭취에서 제외한다.

감정은 완료하면 항상 성공한다. 식물 기술은 작업 속도에 영향을 주고, 낮은 기술 때문에 독버섯을 식용으로 오판하는 기능은 넣지 않는다. 안전하게 선별하는 선택의 비용은 작업 시간이다.

- 작업은 채집 묶음 단위로 진행한다. 같은 출처의 여러 더미는 중복 감정하지 않는다.
- 한 묶음을 확인하면 그 출처의 남은 식물, 원료, 이미 만든 식사에도 결과를 반영한다.
- 여러 출처를 함께 지정하면 각각 감정한다. 첫 묶음의 결과가 다른 묶음에 퍼지지 않는다.
- 작업을 중단하거나 저장 후 불러와도 진행 중인 감정량을 보존한다.
- 완료 결과는 식용 또는 유독 여부와 실제 이름을 보여준다. 대량 작업에서는 개별 편지를 반복하지 않고 결과를 모아 표시한다.

**임시 작업 시간은 식물 기술 5의 정착민 기준으로 채집 묶음 하나당 0.5게임시간이다.** 감정 때문에 야생 채집 자체를 포기하게 되는지, 반대로 항상 무료에 가깝게 감정하게 되는지 확인한 뒤 조정한다. 더미 분할로 시간을 줄이는 구조는 허용하지 않는다.

완성된 식사를 감정할 때도 같은 출처별 시간 기준을 적용한다. 서로 다른 미확인 출처가 두 개 들어 있다면 기본 감정량은 두 묶음이며, 이미 확인된 출처는 다시 검사하지 않는다. 이 시간은 주민의 작업 시간으로, 이동 시간은 별도다.

## 요리와 섭취

미확인 버섯도 일반 식사의 재료로 사용할 수 있다. 요리 작업에 미확인 야생버섯 사용 허용 설정을 두어 플레이어가 위험을 선택하게 한다. 요리는 자동 감정이나 해독 작업으로 취급하지 않는다.

| 대상 | 기본 행동 | 플레이어가 허용했을 때 |
| --- | --- | --- |
| 재배 버섯과 감정된 식용 버섯 | 기존처럼 요리와 자동 섭취 가능 | 기존 행동 유지 |
| 미확인 생버섯 | 자동 생식에서 제외 | 직접 섭취 지시 가능 |
| 미확인 버섯을 요리에 사용 | 작업별 허용 설정은 기본 꺼짐 | 허용한 작업은 일반 식사에 미확인 버섯을 사용 |
| 미확인 버섯을 넣어 만든 식사 | 아직 위험성이 확인되지 않았다면 일반 식사처럼 자동 섭취 가능 | 요리 허용에는 이 결과까지 포함 |
| 감정되거나 중독으로 확인된 독버섯 | 일반 요리와 자동 섭취에서 제외 | 직접 섭취는 가능. 의도적인 요리 사용은 별도 허용 설정 필요 |
| 유독 재료가 확인된 식사 | 자동 섭취를 중단하고 위험성을 표시 | 플레이어의 직접 섭취 지시로만 먹음 |

미확인 재료 사용을 허용하는 작업에는 완성된 식사를 주민이 자동으로 먹을 수 있다는 설명을 함께 둔다. 원료 생식 허용과 요리 허용은 구분한다. 미확인 재료로 이미 만든 식사는 작업 설정을 나중에 끈다고 안전해지지 않는다.

미확인 식사에는 실제 종명 대신 야생버섯 미감정이라는 재료 표시를 사용한다. 원료를 감정하거나 중독으로 원인이 밝혀지면 관련 식사의 재료 표시도 바뀐다. 식사 그림은 기존 식사 그림을 유지하고, 실제 버섯 그림으로 바뀌는 대상은 식물과 원료다.

독버섯을 끓이거나 다른 식재료와 섞어도 게임 내 독성은 유지한다. 단순히 독버섯 재료가 포함되었다는 이유로 모든 식사에 생버섯 한 개와 같은 중독량을 부여하지 않는다. 실제로 들어간 독버섯 종류와 양을 식사별로 보존하고, 먹은 양에 맞춰 중독 노출을 계산한다.

예를 들어 식사 10개를 만들 때 독버섯 원료 한 개를 썼다면, 총 독성량은 원료 한 개분이다. 식사 10개 각각에 원료 한 개분의 독이 새로 생기면 안 된다. 실제 분배와 소량 섭취의 중독 강도는 밸런스 검증으로 정한다.

식용 버섯의 무드 보너스는 기존 +3, +5, +7, 송이 +10과 6시간 지속을 유지하며 가장 높은 효과 하나만 적용한다. 미감정 식용 버섯을 먹었을 때는 실제 종명이 새어나오지 않도록 공통 무드 이름을 사용하되, 종류에 따른 효과량은 보존한다. 독버섯 자체에는 긍정적 무드를 주지 않는다. 식용과 독버섯이 함께 들어간 식사에서는 식용 무드와 중독이 동시에 생길 수 있다.

맛의 효과량에서 간접적으로 종류를 추측하는 단서는 허용한다. 예를 들어 +10 효과는 송이버섯을 추측할 근거가 된다. 숨기는 대상은 감정 전의 실제 이름과 유독 판정 표시이며, 무드 수치까지 같은 값으로 바꾸지는 않는다. 기존에 더 강한 버섯 무드가 남아 있으면 새 효과가 표시되지 않을 수도 있으므로, 무드가 새로 생기지 않았다는 사실만으로 독버섯이라고 확정하지 않는다.

## 중독과 정체 공개

독버섯을 먹으면 종류별 잠복기를 거친 뒤 기존 중독 증상이 시작된다. 잠복기에는 건강 탭, 편지, 의료 작업 우선순위에서 종명이나 중독 사실을 먼저 드러내지 않는다. 현재 v0.4.0의 즉시 노출 알림과 항상 표시되는 건강 상태는 이 규칙에 맞게 변경할 대상이다.

첫 증상이 나타나면 중독 사실과 원인이 된 독버섯 종류를 알려준다. 해당 채집 묶음의 남은 원료와 그 묶음을 사용한 식사의 재료 표시를 갱신하고, 원인 식물이 남아 있다면 함께 확인 상태로 바꾼다.

한 종류의 중독에 여러 출처의 섭취가 누적되면 실제 노출에 기여한 출처를 모두 기록한다. 첫 발병 때는 그 종류의 중독에 기여한 출처들만 확인 상태로 바꾼다. 이미 발병한 같은 종류의 중독에 새로운 출처의 섭취가 추가되면 그 출처도 즉시 확인한다. 다른 종류의 독은 자체 발병 시점에 확인하며, 같은 식사에 섞였다는 이유만으로 모두 공개하지 않는다.

확인된 독성 재료를 대상으로 하는 자동 섭취와 요리를 중단하며, 아직 먹기 전인 해당 음식의 섭취 예약도 취소한다. 이미 먹은 주민의 노출을 되돌리지는 않는다. 다른 출처의 미확인 버섯과 혼합 식사에 들어간 별개의 식용 버섯은 자동 감정하지 않는다.

치료는 기존 의사, 침대, 약품과 의료 허용 설정을 사용한다. 전용 해독제는 추가하지 않는다. 잠복기 동안 증상이 없다는 사실만으로 해당 묶음을 식용으로 확정하지 않는다.

치명적인 두 종류는 첫 증상 경고 이후 치료할 시간을 제공하는 기존 최소 24게임시간 유예를 기준으로 한다. 현재 확인된 범위는 건강한 성인이 한 종류의 독버섯 원료 한 개를 먹는 경우다. 새 요리 경로와 여러 독이 섞인 식사는 따로 검증해야 하며, 독성에 의한 능력 저하가 사망 유예를 우회하지 않도록 설계한다. 다른 부상이나 질병 때문에 생기는 사망은 이 기준과 구분한다.

## 보관과 기존 저장

미확인 버섯은 화면상 하나의 품목으로 다루지만, 실제 종류와 출처 기록을 유지한다. 초안에서는 서로 다른 출처의 미확인 원료 더미를 자동으로 합치지 않는 방식부터 검증한다. 여러 더미는 한꺼번에 감정 지정할 수 있으므로 확인을 위해 하나씩 클릭할 필요는 없다.

식사 더미는 실제로 같은 재료와 독성 구성을 가진 식사끼리만 합친다. 안전한 식사와 독이 든 식사는 같은 더미로 합치지 않는다. 독이 든 식사를 나누거나 운반해도 독성량이 늘거나 사라지지 않아야 한다. 세부적으로 안전한 상태인지 여부가 합치기 동작만으로 드러나지 않도록, 같은 표시 상태의 서로 다른 출처 식사는 동일하게 합치기 제한을 적용한다.

저장 후 불러오기, 운반, 상단 이동 이후에도 실제 종, 출처, 식별 상태, 식사별 원료량, 감정 진행과 중독 진행을 보존한다.

이전 저장에 있던 버섯 식물과 수확물은 현재 이름과 정체를 유지한다. 업데이트 직후 이미 알고 있던 식량을 미확인 상태로 돌리지 않는다. 미확인 시스템은 업데이트 이후 새로 자연 생성되는 버섯부터 적용하며, 기존 재배 식물과 모둠버섯 동작 및 식물 저장 호환 처리를 유지한다.

## 구현과 검증 순서

| 순서 | 구현 대상 | 통과 기준 |
| --- | --- | --- |
| 1 | 출처와 식별 상태 및 공통 표시 | 새 야생만 미확인이고 재배 및 기존 저장은 그대로 유지 |
| 2 | 감정 지정과 완료 변환 | 실제 이름과 기존 그림이 나오고 같은 출처에 결과 공유 |
| 3 | 요리 허용과 식사 원료 기록 | 허용한 작업만 사용하며 종류와 양이 식사에 남음 |
| 4 | 섭취량에 따른 중독과 발병 공개 | 잠복기 정보가 숨겨지고 발병 후 원인만 확인 및 추가 섭취 중단 |
| 5 | 저장 복원과 수량 보존 및 화면 검수 | 분할과 합치기 및 이동 후 독성량이 보존되고 기존 기능 유지 |

검증에는 생식, 식사 한 개 제작, 여러 식사 제작, 서로 다른 버섯 혼합, 식용과 독버섯 혼합, 여러 독 혼합을 포함한다. 원료가 남아 있지 않은 식사의 감정과 감정 예약 중 섭취 차단, 같은 독의 여러 출처 누적 및 발병 후 재섭취에 따른 공개 범위도 확인한다. 저장 전후 정체가 바뀌거나 같은 출처를 다시 감정하는 문제, 잠복기 중 저장 후 불러오기, 발병 직전 식사 예약, 식사 더미 분할, 상단 이동도 확인한다.

일반 화면에서 정보창과 재료 목록 및 무드가 정체를 먼저 노출하지 않는지 확인한다. 기존 10종 무드, 수경재배, 모둠버섯, 야생 출현과 의료 회복을 함께 유지해야 한다. 실행 검증과 실제 화면 검수를 마친 뒤 게임 기능 버전과 배포본을 만든다.
