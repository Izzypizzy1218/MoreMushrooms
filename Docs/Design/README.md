# More Mushrooms 기획 문서

현재 초안은 [야생버섯 시스템 초안 v0.2](WildMushroomIdentification-draft-v0.2-2026-10-09.md)이다. 2026-10-09 사용자 요청으로 감정 기능을 제외했다. v0.5.0에 신규 31종을 포함한 총 46종을 추가했다. v0.6.0은 야생 다양성·발광·고리 군락·제철·균사 재생을 다룬다. v0.6.1은 고급 식용 +15/48시간, 모둠 11종, 꽃송이·자주방망이 맛 설명과 향정신성 6~24시간 조정을 반영했다. v0.6.2는 추가 식용·환각 설명을 다듬었고 v0.6.3은 [전체 맛·환각 설명](../MOOD-v0.6.3.md)에 다양한 비유를 반영했다. 현재 수치는 [v0.6.1 조정](../BALANCE-v0.6.1.md)을 따른다. 미확인 버섯은 구현하지 않는다.

## 야생 생태 제안과 선택 범위

[2026-10-10 제안서](WildEcology-Proposal-2026-10-10/제안서.md)와 원본 ZIP, v3 시설 그림을 함께 보존한다. 사용자는 이 제안 중 **야생 다양성 확대·실제 발광·고리 군락·제철·균사 재생**을 선택했다. 채집 의뢰, 원목/배지 재배시설, 나무·그루터기·비 전용 조건은 이번 구현 범위에서 제외한다. 제안서의 확정 표시와 추천 순서는 이전 검토 기록이며 전체 제안의 구현 승인을 뜻하지 않는다. 현재 구현 설정과 한계는 [v0.6.0 야생 생태](../WILD-ECOLOGY-v0.6.0.md)에 기록한다.

[초안 v0.1](WildMushroomIdentification-draft-v0.1-2026-10-06.md)은 이전 기획 기록으로 보존한다. 그 문서의 감정 기능과 관련 수치는 현재 계획에 포함하지 않는다.

## 향정신성 버섯과 중독 효과

현재 효과·조리 기획은 [향정신성 버섯 요리와 치명적 중독 초안 v0.2](MushroomGameplay-draft-v0.2-2026-10-10.md)이다. 약용 개발을 보류하고, 향정신성 네 종을 별도 약품 제작 없이 일반 요리와 직접 섭취에 연결한다. 무드와 통제 불가 환각 상태, 종별 치명적 중독과 일반 의료 치료를 다룬다. v0.5.0에 향정신성 4종의 일반 요리·무드·통제 불가 효과와 종별 중독·식사 노출 기록을 적용했다. 약용 5종은 채집물만 추가하고 약효·약 제작은 보류했다. 구현 및 검사 범위는 [검증 기록](../VALIDATION.md)을 참고한다.

[효과 초안 v0.1](MushroomGameplay-draft-v0.1-2026-10-10.md)은 이전 기획 기록으로 보존한다. 그 문서의 향정신성 제제 제작은 v0.2에서 삭제했다.
