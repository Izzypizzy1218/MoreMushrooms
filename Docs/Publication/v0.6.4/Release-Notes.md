## 재배·맛 무드·그림

- 11종 모두 재배구역·수경분지 지원. 어둠에서도 자라며 강한 빛에서는 느려진다. 야간 휴식은 유지한다.
- 모둠버섯은 같은 11종을 각 1/11 확률로 선택하며 식물 기술 6이 필요하다. 메뉴의 평균 성장값과 실제 선택 작물의 고유 성장값은 구별한다.
- 고급 야생 5종은 모두 맛 무드 **+15, 48시간**. 나머지 맛 무드 16종은 **+3/+5/+7, 6시간**이다.
- 원물·요리 모두 맛 무드를 주며 가장 높은 효과 하나만 적용한다. 낮은 효과가 높은 효과의 남은 시간을 늘리지 않는다.
- 성장 그림의 크기·군집은 성장률에 따라 달라지고 수확 상자는 1~25개·26~50개·51~75개에서 세 가지 그림을 사용한다.

## 야생 생태 — v0.6.0부터

근거: [야생 생태 기록](../../WILD-ECOLOGY-v0.6.0.md), `Balance/wild_ecology.json`, `Source/WildMushroomEcology.cs`.

- 생물군계별 전체 기본 버섯 가중치를 유지하며 추가 31종의 비중을 늘렸다. 온대림에서는 약 17.82% → 30%이며 실제 지도 개체 비율을 보장하는 수치는 아니다.
- 종별 제철은 새 야생 발생 선택에만 적용한다. 재배 수치와 이미 자란 식물은 유지한다. 열대우림·열대습지는 계절 배율 1을 사용한다.
- 양송이·자주방망이·댕구알·먹물의 드문 고리 군락: 같은 종류 4~7개, 원·반원 형태. 성공 후 최소 3일 간격이다.
- 해당 10종의 성숙한 야생 버섯을 성공적으로 수확하면 30% 확률로 4~6일 후 같은 칸의 어린 개체를 한 번 예약한다. 재배·단순 제거·수확 실패에는 적용하지 않고 재생 개체가 다시 재생을 예약하지 않는다.
- 고리·재생은 지도당 하루 최대 8칸의 추가 예산을 공유한다. 야생 상한은 10,000칸당 80개, 최소 80·최대 1,500개이며 250×250 지도는 500개다. 기존 초과 개체를 삭제하지 않는다.
- 추가 발생은 재배구역·수경분지·지붕 아래·건물 바닥·막힌 칸을 제외한다.
- 발광버섯 반경 2칸·받침애주름 반경 2.5칸의 약한 주변 조명. 태양등 수준 재배광을 제공하지 않으며 수확물은 빛나지 않는다.

v0.6.0 생태 문서에 쓰인 당시의 ‘모둠 9종’은 역사 기록이다. 현재 모둠은 v0.6.1부터 **11종**이다.

## 향정신성·중독

| 종류 | 첫 표준 노출의 기본 무드 | 표준 통제 상실 |
| --- | --- | --- |
| 자유모자·주사위환각 | +15, 6시간 | 6~8시간 |
| 광대 | +10, 6시간 | 8~12시간 |
| 마귀광대 | +10, 6시간 | 12~24시간 |

표준은 원물 10개다. 먹은 양·공통 내성이 실제 무드를 바꾸고 불쾌한 환각은 무드 -8을 줄 수 있다. 향정신성 무드는 4종끼리 중첩되지 않으며 맛 무드와는 별도다. 새 노출은 예정 통제 상실 최소 6시간, 반복 노출을 포함한 한 에피소드는 최초 섭취 시각부터 최대 24시간이다. 수면·쓰러짐 등으로 배회가 먼저 끝날 수 있으므로 실제 배회를 반드시 6시간 지속한다는 뜻은 아니다.

4종은 일반 식재료로 기본 조리에 허용한다. 실제 투입량을 식사 수로 나누어 기록하고 분할·스택·저장에 보존한다. 정책·저장 필터로 향정신성 식사를 제외할 수 있다. 이전에 사용량이 기록되지 않은 식사의 노출량을 새로 추정하지 않는다. 광대·마귀광대는 중독도 함께 적용한다.

독성 정의는 11종이다. 알광대·독우산광대·붉은사슴뿔·녹슨끈적은 충분한 노출에서 기본 치명형, 광대·노란다발은 누적 3단위 이상에서 조건부 치명형이다. 마귀광대는 심한 의식 저하·혼수까지 표현하며 기본 직접 사망 판정은 없다. 다른 증상형도 기본 직접 사망 판정은 없다. 광대·마귀광대 외 독성 수확물은 영양 0의 원료이며 일반 자동 식사·기본 요리에서 제외한다.

치명형의 최소 노출은 0.25단위이며 일반 독버섯 원물 1개가 1단위, 광대·마귀광대는 10개가 1단위다. 치명 판정은 첫 증상 경고 뒤 최소 24게임시간 유예한다. 기본 의료 체계를 이용한 반복 치료가 필요하다. 한 번의 간호 지속시간은 6시간이며, 누적 치료와 안정화 상태는 별도로 유지된다. 이 규칙이 다른 부상·질병의 사망까지 막는 것은 아니다.

시간·용량·독성·치료는 게임 설정이다. 현실 효능이나 종별 의학적 지속시간을 재현한다고 소개하지 않는다. 근거와 각색 범위는 [v0.6.1 조정](../../BALANCE-v0.6.1.md)에 보존한다.

하루 작업 시험은 첫 원물 10개 섭취 이후 기본 AI의 작업·식사·수면을 관찰했다. 준비 후 치료·욕구 보충·강제 각성은 없었다. 이번 주사위환각 폰은 약 6.54시간, 마귀광대 폰은 약 18.89시간 배회했다. 마귀광대는 회복 뒤 수면으로 이어져 이번 하루에는 생산이 없었다. 작은 석재 절단 시험이며 일반 정착지 노동 손실률이나 최적 밸런스를 보장하지 않는다. 자동저장·저장 복원 시험과도 구별한다.

화면에서는 성장 25%·65%·100%와 원물 25·50·75개를 확인했다. 누락·오류 텍스처는 없었으나 축소 상태에서 차가·트러플·새둥지·개미동충하초 등의 어둡거나 가는 초기 개체는 흙과 구분하기 어렵다. 원화는 유지했다. 툴팁 줄바꿈·메뉴 클릭·사용자 해상도·Camera+ 개인 설정 검수까지 수행했다는 뜻은 아니다.

사용자 조합의 기능 검사는 통과했지만 시작 로그의 영어 번역 오류 211개와 Auto Translation의 Google HTTP 429는 별도 환경 문제로 남는다. 개인 ModSettings·API 설정·기존 저장을 복사하지 않은 격리 프로필이다. 전체 로그나 비밀정보를 게시 자료에 넣지 않고 모드 ID·Harmony 소유자·실제 작업 결과만 위 비교 문서에 남겼다.

**기존 저장 복원은 이번 v0.6.4에서 새로 실행하지 않았다.** v0.6.1의 저장 복원·영양죽 기록은 [기존 검증 기록](../../VALIDATION.md)에 있는 과거 시험이며, 이번 130사례나 실제 작업 경로 결과로 바꿔 부르지 않는다. 이번 native 시험은 게임 동작 파일이 같은 v0.6.3 설치본을 사용했고, 최종 v0.6.4의 동작 파일 보존은 별도 대조에서 예상 밖 변경 0으로 확인했다.

실행 ZIP·소스 ZIP·SHA-256은 `Releases/v0.6.4/manifest.json`에서 확인한다. 설치 백업·설치본 해시는 최종 설치 후 검증 기록과 대조한다. 기존 버전 ZIP·이미지 출처·사용자 저장과 활성 모드 설정을 보존하며, 개발용 하네스는 배포 실행 ZIP에서 제외한다.
