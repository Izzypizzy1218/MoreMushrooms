# More Mushrooms v0.6.4 배포 전 검수

검증일: 2026-10-11. RimWorld 1.6.4871 rev591, 공식 Harmony를 사용했다. v0.6.4는 검수·게시 문서 갱신이며 v0.6.3의 생산 C# 9개, DLL, 게임 정의·그림·맛 설명·수치는 유지한다. 네이티브 시험이 사용한 설치본은 v0.6.3이며 게임 동작 파일과 최종 v0.6.4의 바이트 동일성을 별도로 대조한다. 버전 이름만으로 이전 실행을 새 실행이라고 부르지 않는다.

Steam 창작마당 업로드는 사용자가 직접 진행한다. 한국어·영어 설명과 누적 변경 내역은 [Publication/v0.6.4](Publication/v0.6.4/Release-Notes.md)에 준비했다.

## 지도별 초기 분포와 120일 생태

한 지리 시드 `blackjack`에서 생물군계마다 자연 타일 하나를 선정하고 지도 시드 A/B를 비교했다. 아래 대조군은 **현재 런타임에 v0.5 생성 가중치만 적용한 모형**이다. 과거 DLL 실행이 아니며 현재의 계절·서식 규칙은 양쪽에 유지된다. 초기 수치는 지도 생성 직후, 틱 진행·강제 성숙·식물 제거 전에 기록했다.

| 생물군계 | 현재 총수 A / B | 이전 가중치 총수 A / B | 현재 추가 31종 비중 A / B | 이전 비중 A / B |
|---|---:|---:|---:|---:|
| 온대림 | 392 / 361 | 391 / 360 | 31.9% / 29.4% | 18.7% / 18.1% |
| 온대습지 | 317 / 320 | 321 / 315 | 11.0% / 10.9% | 6.9% / 5.7% |
| 아한대림 | 0 / 0 | 0 / 0 | 해당 없음 | 해당 없음 |
| 건조관목림 | 5 / 4 | 6 / 5 | 40.0% / 50.0% | 50.0% / 40.0% |
| 열대우림 | 119 / 124 | 118 / 125 | 37.0% / 38.7% | 22.0% / 24.0% |
| 열대습지 | 48 / 50 | 49 / 54 | 25.0% / 26.0% | 16.3% / 16.7% |
| 툰드라 대조 | 0 / 0 | 0 / 0 | 해당 없음 | 해당 없음 |

온대림은 총수가 거의 같으면서 추가종 비중이 높아졌다. 건조관목림은 표본이 4~6개라 비중 차이에 의미를 부여하기 어렵다. 두 지도 시드는 출현 확률의 통계 추정치가 아니며, 특정 타일의 관측을 전체 생물군계에 일반화하지 않는다.

온대림의 120일 무채집 조건은 시드별 고리 8회씩, 채집 조건은 10회·9회와 재생 54개·55개를 기록했다. 열대우림은 고리 0회, 채집 조건의 재생 12개·10개였다. 일일 추가 예산과 지도 상한·개체 및 대기표 보존을 확인했다. 수확 실패는 실제 표본에 없어 그 분기의 경험적 검증으로 해석하지 않는다.

아한대림은 초기 −2.84°C에서 개체 0으로 시작했고, 여름 최고 21.41°C에서도 모형의 개체는 0이었다. 이 생물군계에는 고리 대상 4종의 생성 가중치가 없고, 모형은 기본 자연 재파종을 생략하므로 새 공급원이 없기 때문이다. 초기 눈은 0으로 이 결과의 원인이 아니다. 장기 12개 조건 모두 초기 눈이 없어 실제 양의 눈이 녹는 경로는 미관측이며, 툰드라의 눈은 초기 생성 조건으로만 확인했다.

120일 모형의 채집 수치는 이동·노동·식품 안전·보관을 제외한 원물 잠재량이다. Nutrition이 0인 재료와 향정신성·독성 식재료도 포함하므로 이를 식량 수입으로 환산하지 않는다. 기본 자연 재파종이 없는 조건에서 개체 소진은 실제 게임의 장기 감소를 뜻하지 않는다. [생태 요약과 원시 집계](TestResults/v0.6.4-Ecology-Summary.md)에 종별 발견·계절·원물 구분·시드와 무결성을 기록한다.

## 환각과 치료 부담

첫 표준 섭취를 종마다 3회 관찰한 실제 정신상태 시간은 자유모자 6.54–7.02시간, 주사위환각 6.54–7.26시간, 광대 8.82–11.88시간, 마귀광대 13.08–18.48시간이었다. 맛과 별도의 향정신성 무드는 6시간이었다. 수면·마취 조건은 실제 정신상태를 일찍 끝냈고 같은 노출로 재시작하지 않았다. 반복 섭취의 공포·내성과 최대 24시간의 예약 상한도 검사했다. 이 소표본의 공포 비율은 모집단 발생 확률로 해석하지 않는다.

치명형 4종은 무치료 8사례 모두 사망했다. 첫 경고 뒤 사망까지 73.92–87.24시간으로, 최소 24시간 유예를 지켰다. 즉시 치료한 사례는 생존했다. 산업약을 완치까지 재치료 가능한 즉시 계속 사용한 프로토콜에서는 14–24개가 소모됐다. **이 수치는 생존에 필요한 최소 약품량이 아니다.** 안정화 후 치료를 멈추는 조건은 측정하지 않았다. 경고 뒤 72시간 늦게 치료한 표본도 생존했지만, 붉은사슴뿔은 최고 중증도 0.938과 장시간 쓰러짐을 보였다.

시험 의사는 정상 건강·의학 10으로 실제 치료 품질 stat가 110%였고, 약품은 무제한이며 이동·간호 대기 시간이 없었다. 환자의 욕구·작업 AI와 정착지 경제도 이 단독 경과 시험에서는 진행하지 않았다. 원물의 기본 2% 식중독은 제거하지 않았으며 한 자유모자 반복 사례에서 쓰러짐이 함께 관찰됐다. 이를 자유모자 자체의 고정 통제 상실 시간으로 해석하지 않는다. 150틱 가속 시계와 구토 job bookkeeping 처리 등 세부 조건은 [130사례 요약](TestResults/v0.6.4-Balance-Summary.md)에 기록했다.

현재 수치는 무드 보상보다 긴 명령 불가 시간, 반복 섭취의 공포, 치명형의 장기간 회복이라는 비용을 갖는다. 이 검수에서는 사용자가 정한 효과·시간·치료 수치를 임의로 바꾸지 않았다.

## 실제 24시간 작업 비교

동일한 건강·유전자·기술·욕구·온도와 재료를 준비한 성인 인간 3명에게 감자·주사위환각·마귀광대 원물 10개씩을 실제로 먹였다. 이후 실제 게임 틱과 자율 작업 AI를 진행하며 각 섭취 시점부터 정확히 60,000틱을 관찰했다. 모두 같은 석재 작업대·재료·안전한 식사·침대를 갖췄으며 관찰 중 추가 명령·치료·강제 기상·욕구 복원은 하지 않았다.

| 조건 | 완성 석재 | 실제 제작 작업 시간 | 버섯 정신상태 | 수면 |
|---|---:|---:|---:|---:|
| 감자 대조 | 400개 | 16.080시간 | 0시간 | 6.220시간 |
| 주사위환각 | 260개 | 10.452시간 | 6.537시간 | 5.913시간 |
| 마귀광대 | 0개 | 0시간 | 18.886시간 | 5.016시간 |

주사위환각은 통제 회복 후 작업에 복귀했고, 마귀광대는 긴 배회 뒤 잠들어 이 관찰창 안에서 제작하지 않았다. 두 사례 모두 무드 이득에 따른 실제 작업 중단이 확인됐지만 **종마다 1명뿐인 작은 작업실 사례**다. 주사위의 생산량 65%와 마귀의 0%를 일반 정착지의 노동 효율로 사용하지 않는다. 이 사례에서는 원물 식중독·쓰러짐·사망이 없었으나 다른 실행의 발생을 배제하지 않는다.

화면 없는 실행의 하루째 동기 자동저장은 GUI 표시를 기다려 시험이 멈출 수 있어, 최종 격리 프로필은 자동저장 간격을 99일로 설정했다. 사용자 설정을 바꾸지 않았으며 이 시험은 저장·복원 또는 자동저장 검증이 아니다. 유전자 준비 실패와 자동저장 대기가 있었던 이전 실행은 최종 수치에서 제외했다. [작업량 요약과 원시 자료](TestResults/v0.6.4-Work-Summary.md)에 시계·동등성·수면·작업·무드 적분과 한계를 기록한다.

## 실제 화면

46종을 자연 성장 상태(`sown=false`) 25%·65%·100%와 원물 25·50·75개로 배치했다. 야생 팽이는 야생 변형을 사용했다. 1600×1000 화면에서 카메라 RootSize 18과 32, 칸당 약 27.8픽셀과 15.6픽셀을 비교했다. 이는 배치·성장률을 고정한 시각 시험이며 자연 발생 모습이나 성장 속도 측정은 아니다.

- 46종 모두 그림 누락·보라색 오류 텍스처 없이 표시됐다. 성장률에 따른 크기·군집과 세 단계 수확 상자를 확인했다.
- 축소 시 차가·트러플·새둥지·개미동충하초처럼 어둡거나 가는 초기 개체는 흙과 구분하기 어렵다. 승인된 원화를 유지했으며 저대비 보완은 후속 후보로 남긴다. 전체 종이 축소 상태에서도 쉽게 식별된다고 주장하지 않는다.
- 밤의 발광버섯·받침애주름은 가까운 칸에만 약한 조명을 냈다. 자체 칸의 GroundGlow는 0.5, 동쪽 인접 칸은 각각 약 0.141·0.325, 3칸 떨어진 곳은 0이었다. 양송이 대조군은 0이었다. 이는 재배용 강한 조명이 아니다.
- 촬영 프로필에서 선택적인 기본 발광 식물 참조 Def를 찾지 못해 해당 슬롯은 비었다. 프레임 상단의 참조 문구는 실제 네 번째 개체의 존재를 증명하지 않는다. 발광 비교는 두 모드종과 양송이 대조군으로 한정한다.
- 야간 두 프레임의 SkyGlow가 0과 약 0.0173으로 달라, 스크린샷끼리 밝기를 정량 비교하지 않는다. 위 GroundGlow 값은 별도의 네이티브 격자 측정이며, 밝은 갓 자체가 주변 조명과 같은 뜻은 아니다. [독립 화면 검수](TestResults/v0.6.4-Visual-Summary.md)에 이미지별 판단을 기록한다.

화면 조작 도구는 커널 초기화 오류로 사용할 수 없었다. 대신 네이티브 `ScreenCapture.CaptureScreenshot`으로 실제 게임 프레임을 저장하고 직접 확인했다. 메뉴 클릭·툴팁 줄바꿈·사용자 해상도·Camera+ 설정까지 확인한 것은 아니다. 캡처에는 시험 정착지의 Game Over 알림과 준비 중 지붕 제거 메시지가 남을 수 있다.

## 사용자 활성 모드 조합

기본 조합과 사용자 활성 79개에 시험 하네스 하나를 추가한 조합에서 각각 42개 검사를 통과했다. 실제 폰이 성숙한 재배 양송이를 수확하고 기본 조리대에서 네이티브 조리 작업을 수행한 뒤 식사를 섭취했다. 주사위환각 원물 40개로 만든 4끼는 한 끼당 표준 1단위와 +15/6시간을, 송이 식사는 +15/48시간을 적용했다. 향정신성 음식 정책 차단과 폰의 섭취 허용 판정, 식사 분할·병합의 용량 보존, 일반 식사와의 스택 분리를 확인했다.

전체 모드 시작 로그에는 영어 번역 오류 211개와 AutoTranslation의 Google 429 응답이 있었다. 버섯 기능 검사 통과와 구분하며 번역 서비스 재시도나 차단 우회는 하지 않았다. 개인 모드 설정·API 키를 복사하지 않아 해당 서비스의 개인 설정 동작까지 검증한 결과는 아니다. 두 프로필의 초기 외기 온도가 달랐으므로 조리 소요 시간을 성능 비교로 사용하지 않는다. 전체 목록·추가 Harmony 패치 소유자·조건은 [호환성 검수](TestResults/v0.6.4-Compatibility-Summary.md)를 참고한다.

## 남는 한계

120일 생태 시험은 기본 야생 재파종·동물·날씨 변화·사건·채집 이동 노동을 생략한 통제 모형이다. 전체 실제 정착지의 식량 공급량이나 장시간 플레이를 보장하지 않는다. v0.5 비교도 현재 런타임에서 이전 생성 가중치만 바꾼 대조이며, 과거 DLL을 실행한 결과가 아니다.

사용자 조합 시험에는 활성 모드 목록을 복사하지만 개인 모드 설정·API 키·기존 저장은 복사하지 않는다. 모드 전용 조리기, 별도 식품 생산·스택 API, 자동 음식 탐색 전체, 외계 종족의 독특한 섭취, 개인 저장의 조리 작업 이행까지 포함하는 전면 호환 보장은 아니다. 이전 v0.6.1의 저장 복원·영양죽 시험 기록은 역사적 증거로 구분한다.

약용 효과·약 제작, 감정·미확인 품목, 채집 의뢰, 전용 원목·배지 시설, 숙주·수목·목재·최근 비 발생 조건은 계속 보류한다.
