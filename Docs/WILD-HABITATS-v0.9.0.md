# v0.9.0 숙주·목재·비와 야생 서식 확대

기록일: 2026-10-11. v0.8.0의 작은 군락과 여섯 종의 나무 조건에 숙주·목재 연계, 비 뒤 군락, 추가 서식 조건과 예비 공급 제한을 더합니다. 버섯 종류·그림·먹는 효과는 늘리지 않습니다.

사용자가 지정한 다섯 작업을 함께 구현하되, **이번 단계에서는 컴파일·정적 정의·보존만 검사합니다. 실제 게임 실행, 저장 복원, 화면, 사용자 모드 조합과 장기 균형 검증은 이후 약용·약 제작과 버섯 요리 시스템까지 추가한 뒤 한 번에 진행합니다.** 아래 수치는 게임용 예비 설정이며 현실 생태의 정확한 재현이나 확인된 최종 공급량이 아닙니다.

## 숙주와 목재

| 버섯 | 새 발생 조건 | 적용하지 않는 효과 |
|---|---|---|
| 동충하초·개미동충하초 | 살아 있는 림월드 곤충이나 곤충 사체에서 격자 거리 1~2칸의 적합한 빈 흙 | 감염·숙주 조종·곤충 사망·사체 소모 |
| 집버섯 | 비에 노출되는 목재 바닥 또는 노출된 목재 건물 옆의 적합한 빈 흙 | 건물·바닥 부식, 체력 피해, 목재 소모 |

‘비에 노출되는 목재’는 지붕 없는 칸 또는 시야가 이어지는 2칸 안쪽의 지붕 구멍으로 판정합니다. 온전한 벽 너머 야외 칸만 있다는 이유로 실내를 노출된 것으로 취급하지 않습니다. 목재 바닥·다리 또는 목재 건물 주변의 빈 흙을 집버섯 전용 발생 자리로 사용하고, 건물 자체가 차지한 칸에는 버섯을 만들지 않습니다. 모드 목재는 목재 재질·태그·건설 비용으로 식별합니다.

목재 바닥에서 자연 발생한 집버섯은 토양 비옥도 대신 목재를 기질로 사용해 성장할 수 있도록 별도 성장 판정을 둡니다. 온도·광량·유독 안개·가뭄·강한 빛의 기존 배율은 유지합니다. 바닥 자체의 비옥도와 다른 식물의 성장 규칙을 바꾸지 않으며 집버섯의 기본 성장일수·수확량도 그대로입니다. 이 새 목재 성장 경로의 실제 게임 동작은 마지막 통합 검증에 포함합니다.

환경 전용 보조 발생에는 동충하초·개미동충하초·노란각시·집버섯이 참여합니다. 지도 초기 대기 15일 이후 시간마다 3% 기회를 검사하고 성공하면 최소 15일을 다시 기다립니다. 한 번에 같은 종 1~2개만 만들고 추가 발생 공통 예산을 사용합니다. 조건이나 빈자리가 없으면 아무것도 만들지 않습니다. 이는 ‘정확히 15일에 한 번’이 아니며 실제 빈도는 긴 시간의 실측으로 확인할 예정입니다.

## 비가 그친 뒤 군락

지도에서 3게임시간 이상 이어진 비를 관측하고 비가 그치면 첫 비 없음 판정부터 48게임시간의 기회 창을 엽니다. 창 안에서 시간마다 3.5% 기회를 검사하고 종별 서식·생물군계·제철 조건을 통과하면 같은 종 2~5개의 작은 불규칙 군락을 시도합니다. 성공하면 해당 비 구간의 기회를 소모하고 최소 2일을 기다립니다. 여러 짧은 소나기를 무조건 합산하지 않습니다.

- 비가 온 모든 지도에 반드시 군락이 생기는 것은 아닙니다.
- 재배구역·수경분지·건물이 점유한 칸은 제외합니다. 일반종은 야외 흙을 사용하며 집버섯은 위 노출 목재 조건의 바닥·지붕 예외를 따릅니다. 노란각시의 실내 흙 군락은 비 뒤 경로에서 제외합니다.
- 빈자리·지도 상한·남은 예산이 부족하면 계획한 군락을 만들지 않습니다. 사전 배치 뒤 실제 발생 단계에서 일부 칸이 실패할 가능성까지 실제 게임에서 검증한 상태는 아닙니다.
- 이미 있던 버섯을 옮겨 비 뒤 군락인 것처럼 보이게 만들지 않습니다. 이 경로는 제한된 추가 발생입니다.
- 저장에 없는 이전 날씨를 추정하지 않고 새 버전이 관측한 비부터 기록합니다. 새 관측·대기 상태의 실제 저장 복원은 마지막 통합 검증에 포함합니다.

## 종별 서식 장소

단순히 현실의 ‘습기’나 ‘유기물’을 가정하지 않고, 플레이어가 지도에서 볼 수 있는 나무·풀·지붕·흙·물·버섯·목재·곤충으로 조건을 표현합니다. 기존 재배 11종의 파종에는 야생 전용 조건을 강요하지 않습니다.

| 서식 유형 | 적용 종 | 게임에서 찾는 장소 |
|---|---|---|
| 들판 | 댕구알·먹물·자유모자 | 2칸 안에 풀, 5칸 안에 살아 있는 나무 0~1그루가 있는 야외 흙 |
| 숲 가장자리 | 자주방망이·곰보·망태·악마손가락·새둥지 | 5칸 안에 살아 있는 나무 1~3그루가 있는 야외 흙 |
| 나무 밑 | 독우산광대·트러플·파란젖·영지·상황·알광대·녹슨끈적 | 성장률 50% 이상인 살아 있는 나무에서 1~2칸 떨어진 흙 |
| 그루터기 주변 | 노란다발·화경·구름·잭오랜턴·뽕나무·발광·노란뇌·받침애주름 | 그루터기나 죽은 나무에서 1~2칸 떨어진 흙 |
| 꽃송이 전용 | 꽃송이 | 그루터기·죽은 나무 또는 성장률 50% 이상의 살아 있는 소나무 주변 |
| 어두운 실내 흙 | 노란각시 | 지붕이 있고 바닥을 깔지 않은 흙, 밝기 30% 이하 |
| 다른 버섯 주변 | 랍스터 | 다른 종류의 야생 모드 버섯에서 1~2칸 떨어진 빈 흙 |
| 곤충 주변 | 동충하초·개미동충하초 | 살아 있는 곤충이나 곤충 사체에서 1~2칸 떨어진 흙 |
| 노출 목재 | 집버섯 | 위 노출 목재 조건에 맞는 목재 바닥·다리 또는 목재 건물 주변 흙 |

기존 나무 조건 6종에 새 서식 조건 29종을 더해 총 35종에 전용 조건을 둡니다. 나머지 11종은 기존 적합한 흙 조건을 유지합니다. 거리는 대각선을 포함한 격자 기준이며 숙주·나무의 점유 칸을 제외합니다. 림월드 Core의 그루터기는 잘린 나무의 종을 유지하지 않으므로 꽃송이는 그루터기 수종을 가리지 않습니다. ‘물가 흙’ 판정 도우미는 준비되어 있지만 이번 종별 설정에는 연결하지 않았으며 완료한 서식 종으로 세지 않습니다.

종별 연결과 세부 반경은 `Balance/wild_ecology.json`의 생성 원본에 기록합니다. 자동 생성한 영문·한글 식물 설명에도 각 조건을 반영합니다. 서식 조건은 새 자연 발생·추가 군락·균사 후보에 적용하며 이미 자란 버섯을 조건 불일치로 제거하지 않습니다.

## 여섯 나무 조건 종의 발견 기회

| 버섯 | 나무 |
|---|---|
| 송이 | 소나무 |
| 차가 | 자작나무 |
| 포르치니·블랙트럼펫·광대·마귀광대 | 종류 제한 없는 살아 있는 나무 |

성장률 50% 이상의 나무에서 대각선을 포함한 격자 거리 1~2칸을 사용하고 나무 점유 칸은 제외합니다. 자연 지도 생성의 나무 배치 순서로 이 종들이 거의 선택되지 않을 가능성을 줄이기 위해, 조건에 맞는 종을 골라 드물게 2~3개 보조 발생을 시도합니다. 지도 초기 대기 5일 이후 시간마다 1.5% 기회를 검사하고 성공하면 최소 5일을 다시 기다립니다. 제철·해당 생물군계·적합한 자리를 계속 검사하며 나무가 없는 지도에 강제로 만들지 않습니다.

후보는 그 지도에서 기본 야생 발생 가중치가 0보다 큰 여섯 종으로 한정합니다. 보조 선택에서는 `제철 배율 / (1 + 현재 해당 종 야생 개체 수)`로 적은 종에 기회를 더 줍니다. 기본 commonality 값의 크기는 이 보조 경로의 선택 비율에 사용하지 않으며 원래 자연 발생 commonality 자체도 바꾸지 않습니다.

이 여섯 종의 균사 재생 확률은 0을 유지합니다. 보조 발생은 수확 자리를 무한 반복 생산하는 기능이 아닙니다. 발견 비중·최초 발견까지의 시간은 마지막 여러 시드·장기 시험에서 확인합니다.

## 총량과 기존 기능

기본 발생 가중치의 v0.6.4 대비 50% 감소·재배 가능 11종 20% : 야생 전용 35종 80% 설정은 유지합니다. 이는 기본 선택 가중치이며 서식 조건과 추가 발생을 합한 실제 개수·비율을 보장하지 않습니다.

비 뒤 군락·환경 전용 발생·여섯 종 보조 발생·기존 고리·균사는 **지도당 하루 8개 추가 발생 예산**을 공유하고 기존 지도 상한을 지킵니다. 각각 별도의 8개를 받지 않습니다. 군락 크기·대기시간·희귀종 보조는 공급을 억제하며 시작하기 위한 예비 설정입니다. 장기간 결과가 과하거나 드문지는 아직 측정하지 않았습니다.

v0.8.0의 초기 군락 재배치는 기본 생성량을 보존하지만 위 추가 발생 경로는 제한 안에서 버섯을 더 만듭니다. 둘을 같은 ‘수량 보존’ 기능으로 표현하지 않습니다. 작은 군락 2~5개는 목표이며 예전 큰 군락·자리 부족 시 원래 수량 우선 보존의 예외는 유지합니다. 기존 고리 군락 4~7개와 일부 일반종의 1회 균사 재생, 제철과 발광도 유지합니다.

기존 저장의 식물 위치·성장·나이·식별자는 변경하지 않습니다. 재배·수경·모둠 11종의 확률, 성장일수·수확량·가치·영양·맛·환각·독성·치료·섭취 설정과 그림도 유지합니다. 새 관측·보조 발생 상태의 저장 필드는 추가하지만 과거 날씨를 소급해 채우지 않습니다. 실제 이전 저장을 불러오는 검사는 이번에 수행하지 않습니다.

## 다음 단계와 배포 경계

다음 별도 요청에서 약용 버섯의 약효·약 제작을 추가하고, 그 이후 버섯 요리 시스템을 추가한 뒤 통합 검증합니다. 약효·약 제작은 이번에 구현하지 않으며 사용자가 영구 보류한 기능으로도 취급하지 않습니다. 감정·미확인 버섯과 향정신성 추출물·별도 약 제작은 제외한 결정을 유지합니다. 숙주 감염·목재 피해·채집 의뢰·원목/배지 재배시설도 이번 범위 밖입니다.

v0.8.0 README는 [실행 ZIP 원본](History/README-v0.8.0.md)을 그대로 보존합니다. 버전별 실행·소스 ZIP·SHA-256과 이전 설치 백업을 남기는 절차는 유지합니다. GitHub·Steam 게시를 이번 단계에서 진행하지 않으며 Steam 창작마당 업로드는 사용자가 담당합니다.

## 이번 검사와 남은 검증

설치된 RimWorld 1.6.4871 rev591 어셈블리를 참조한 Release 컴파일, 정적 검사 **3,438개**, v0.8.0 대비 보존 대조 **615개**를 통과했고 정의 생성 반복 실행에서 **292파일이 동일**했습니다. 기존 배포 파일 72개·사용자 설정 48개·사용자 저장 45개의 해시도 보존했습니다. 상세 증거는 [검증 기록](VALIDATION.md)에 연결합니다.

**이번에는 게임을 실행하지 않았습니다.** 빌드 기록의 `gameLaunched`와 `nativeRuntimeValidated`는 모두 `false`입니다. 기본 검사 통과를 새 발생 경로·저장·균형·화면의 실제 게임 검증으로 간주하지 않습니다. 버전별 패키지와 최종 설치 파일 대조는 `Releases/v0.9.0/`의 manifest와 별도 설치 기록으로 확인합니다.

실제 게임 실행·새/이전 저장 복원·날씨 전이·비 창 중 재저장·곤충/사체 제거·목재/지붕 변경·모드 그루터기·장기 발생량·여섯 종 희소성·실제 화면은 이번에 새로 검사하지 않습니다. 이전 v0.8.0 통과 기록은 당시 버전의 증거이며 새 v0.9.0 기능의 검증 결과가 아닙니다. 마지막 통합 검증에서는 약용·요리의 실제 작업·섭취·정책·저장 호환성과 함께 이 항목을 확인합니다.
