# More Mushrooms v0.6.0 — 야생 다양성과 생태

2026-10-10 제안 중 사용자가 선택한 야생 다양성·발광·고리 군락·제철·균사 재생을 다룹니다. 버섯 46종과 재배 가능한 11종, 모둠 9종, 기존 성장·수확·맛·중독·향정신성 효과는 유지합니다. 모든 계절·확률·간격은 게임용 설정입니다.

## 생성 가중치

온대림의 전체 버섯 가중치 합계 0.1375를 유지하면서 신규 31종의 가중치 비중을 약 17.82%에서 30%로 조정합니다. 기존 재배 식용의 야생 가중치는 약 18.41% 줄이고, 신규종을 분류별로 늘립니다. 송이와 기존 독버섯 5종의 가중치는 유지합니다.

다른 생물군계도 버섯의 전체 기본 가중치를 유지합니다. 등록된 신규 종류가 적은 지역에서는 기존 재배 식용의 감소 폭을 완화합니다. 기본 가중치는 생물군계의 다른 식물, 지역별 식물 보정, 계절·온도·비옥도와 함께 작동하므로 실제 지도 개수나 신규종의 정확한 발견 비율을 뜻하지 않습니다. 기존 지도에 있는 버섯을 삭제하거나 다른 종류로 바꾸지 않습니다.

## 제철

종별 봄·여름·가을·겨울 배율을 야생 식물의 선택 가중치에 적용합니다. 현지 계절을 사용하므로 남반구에서는 계절이 반대로 적용됩니다. 영구 여름은 여름 배율, 영구 겨울은 겨울 배율을 사용합니다. 열대우림·열대습지는 배율을 1로 둡니다. 온도 등 기존 생장 가능 조건은 별도로 유지합니다. 네 계절의 설정 배율 평균은 1이지만 실제 연간 발생량은 기후와 기본 게임의 보정에 따라 달라집니다.

제철은 새로 발생하는 야생 버섯의 빈도만 바꿉니다. 이미 자란 버섯을 지우거나 성장을 멈추지 않으며, 지상 재배와 수경재배의 파종·성장·수확 수치는 바꾸지 않습니다.

## 발광

발광버섯과 받침애주름버섯 식물에 기본 게임의 조명 컴포넌트를 사용합니다. 두 종류의 빛은 각각 반경 2칸·2.5칸의 약한 녹색 계열이며, 태양등처럼 재배용 밝기를 제공하지 않습니다. 식물의 생성과 저장 복원 시 등록되고, 수확·베기·파괴·지도에서 제거할 때 해제됩니다. 수확물 상자는 빛을 내지 않습니다.

## 고리 군락과 균사 재생

양송이·자주방망이·댕구알·먹물버섯은 드물게 같은 종류 4~7칸이 반경 2.5~4칸의 원 또는 반원 형태로 발생합니다. 한 시간마다 제한된 후보를 검사하며 검사당 군락 시도 확률은 1.5%입니다. 성공 후 최소 3일 동안 다음 자연 군락 시도를 쉬고, 빈자리가 부족하면 발생하지 않습니다. 비·특정 나무·그루터기·숙주를 검사하는 기능은 이번 범위에 포함하지 않습니다.

균사 재생은 양송이·표고·느타리·야생 팽이·목이·느티만가닥·자주방망이·먹물·구름·뽕나무버섯 10종의 성숙한 야생 식물을 성공적으로 수확했을 때 30% 확률로 예약합니다. 4~6일 뒤 원래 칸에 어린 식물 하나가 다시 발생하며, 이후 기존 성장 규칙을 따릅니다. 재배한 식물, 그냥 베거나 파괴한 식물, 수확 실패는 재생을 예약하지 않습니다. 재생한 개체는 다시 균사를 남기지 않아 같은 자리에서 무한히 수확할 수 없습니다. 예약과 개체의 재생 여부는 저장·불러오기에 보존합니다.

고리 군락과 균사 재생은 합쳐서 지도당 하루 최대 8칸의 추가 발생 예산을 사용합니다. 지도별 야생 버섯 상한은 지도 10,000칸당 80개(최소 80·최대 1,500개)이며 기본 야생 발생도 이 상한을 공유합니다. 250×250 지도는 500개입니다. 재배한 버섯은 상한에 포함하지 않습니다. 재배구역·수경분지·지붕 아래·건물 바닥·다른 식물이나 건물이 있는 칸에는 새 개체를 만들지 않습니다. 막힌 자리를 비우려고 기존 사물을 삭제하지 않습니다.

상한은 v0.5.0 격리 저장의 250×250 지도에 원래 생성된 야생 버섯 357개를 수용하도록 잡았습니다. 기존 지도에 상한보다 많은 버섯이 있어도 지우지 않습니다. 모든 시드·지도·기후에서 같은 수가 발생한다는 뜻은 아닙니다.

균사 예약은 최대 64개입니다. 예정일 이후 최대 8일 동안 예산·온도·일시적인 점유 해소를 기다립니다. 그 사이 바닥을 깔거나 지붕·재배구역·건축물을 만들면 해당 예약을 취소합니다.

전체 지도에 무제한으로 반복 검사하지 않으며 일정 간격에 제한된 후보만 검사합니다. 이미 생성된 식물이 상한보다 많아도 제거하지 않습니다.

개발자 모드에서는 디버그 작업의 **More Mushrooms → Spawn wild mushroom ring**으로 고리 군락 생성을 시도할 수 있습니다. 빈 흙이 충분한 야외를 선택하세요. 이 작업도 발생 예산과 지도 상한, 유효한 위치 조건을 따릅니다.

희귀 버섯 채집 의뢰, 원목 재배대·배지 재배통, 나무·그루터기·최근 비·곤충·목재 전용 발생, 약용 효능·약 제작·감정은 구현하지 않습니다. 제안서의 그림과 전체 기획은 `Docs/Design/WildEcology-Proposal-2026-10-10/`에 원본 ZIP과 함께 보존합니다.

실행 검사와 저장 복원 결과 및 미검증 범위는 [검증 기록](VALIDATION.md)을 참고하세요. 설정의 한 원본은 `Balance/wild_ecology.json`이며, 생성한 XML을 게임에 배포합니다.
