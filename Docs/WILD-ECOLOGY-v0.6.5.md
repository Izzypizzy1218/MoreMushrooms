# More Mushrooms v0.6.5 — 야생 발생량과 구성 조정

사용자가 실제 온대림 전체 지도 미리보기를 비교한 뒤 선택한 **50% 감소안**을 적용합니다. 총 46종 중 **재배 가능한 11종의 야생 발생 비중을 20%, 야생 전용 35종을 80%**로 맞추는 것이 목표입니다. 고급·특이 식용처럼 먹을 수 있어도 재배할 수 없는 종류는 야생 전용 35종에 포함합니다.

## 가중치 계산

각 지원 생물군계에서 v0.6.4의 기본 발생 가중치에 봄철 제철 배율을 곱한 값을 기준으로 삼습니다. 열대우림과 열대습지는 기존 생태 코드에 따라 모든 종의 계절 배율을 1로 계산합니다.

기준 유효 가중치 합계를 `S`, 재배 가능한 그룹의 합계를 `C`, 야생 전용 그룹의 합계를 `W`라고 할 때, 기존 기본 가중치에 다음 배율을 적용합니다.

| 그룹 | 기본 가중치에 적용할 배율 | 봄철 목표 유효 합계 |
|---|---|---|
| 재배 가능한 11종 | `S × 0.5 × 0.2 / C` | `S × 0.1` |
| 야생 전용 35종 | `S × 0.5 × 0.8 / W` | `S × 0.4` |

각 그룹 안에서는 기존 종별 가중치의 상대 비율을 유지합니다. 지원 지역에 등록하지 않았던 종류를 새 생물군계에 추가하지 않습니다. 파종용 팽이와 야생 팽이를 중복 집계하지 않으며, 야생 팽이의 실제 발생 정의를 재배 가능 그룹의 팽이 항목으로 계산합니다.

생성한 기본 가중치가 생물군계마다 고정되므로 다른 계절에도 같은 설정을 사용합니다. 다른 계절에는 기존 종별 제철 배율이 다시 적용되어 전체 감소폭과 두 그룹의 비중이 봄철 목표와 달라질 수 있습니다. 이것은 연중 모든 계절에 정확한 50% 및 20:80을 강제하는 기능이 아닙니다.

온대림의 계절별 계산값은 다음과 같습니다. 모두 v0.6.4의 **같은 계절 유효 가중치**와 비교한 값이며 실제 지도 개수가 아닙니다.

| 계절 | v0.6.4 대비 전체 유효 가중치 잔존율 | 재배 가능한 그룹의 유효 가중치 비중 |
|---|---:|---:|
| 봄 | 50.0000% | 20.0000% |
| 여름 | 48.9252% | 20.9519% |
| 가을 | 46.3338% | 23.4285% |
| 겨울 | 53.2755% | 17.3360% |

조정 원본은 `Balance/mushrooms.json`, `Balance/poison_mushrooms.json`, `Balance/expansion_mushrooms.json`의 생물군계별 가중치입니다. `Scripts/rebalance_wild_weights.py`가 v0.6.4 기준값으로 계산하며, 같은 결과를 반복 생성해도 가중치가 거듭 줄어들지 않도록 처리합니다.

## 실제 발생과 기존 저장

기본 게임은 버섯만 따로 정해진 개수만큼 만드는 대신 다른 야생 식물과 함께 종류를 선택합니다. 종별 기존 밀도 보정, 군집, 온도·비옥도, 빈자리, 모드의 계절·발생 상한이 함께 작동하므로 **가중치 50% 감소는 모든 지도에서 정확한 개체 수 50% 감소를 뜻하지 않습니다.** 실제 두 그룹의 개수도 정확히 20:80일 필요는 없습니다.

새 지도 초기 생성과 이후 기본 야생 식물 선택에 조정한 가중치를 적용합니다. 기존 저장에 이미 자라는 버섯은 그대로 두고, 강제로 제거하거나 종류를 바꾸지 않습니다. 재배구역·수경분지·모둠 파종과 기존 성장일수·수확량·맛 무드·향정신성·독성·치료·그림·식별자는 유지합니다.

## 고리 군락·균사 재생과 상한

선택에 사용한 미리보기와 동일하게 **고리 군락·균사 재생의 확률과 추가 발생 예산, 야생 버섯 상한은 유지**합니다. 하루 추가 발생 예산은 지도당 8칸이며, 상한은 10,000칸당 80개·최소 80개·최대 1,500개로 250×250 지도에서는 500개입니다. 이는 도달해야 하는 목표 개수가 아니라 새 발생을 막는 상한입니다.

고리 군락 시도 확률은 검사당 1.5%, 성공 후 쉬는 기간은 3일입니다. 기존 대상 10종의 성공적인 야생 수확 뒤 균사 재생 예약 확률 30%, 재생 대기 4~6일과 1회 제한도 유지합니다. 따라서 이번 조정은 이러한 추가 생태 과정까지 모두 정확히 절반으로 줄이거나 장기간 공급량을 절반으로 강제하는 변경이 아닙니다. 발광·제철·발생 위치 제한과 생태 예약의 저장 방식, 생산 C#과 DLL도 유지합니다.

## 선택에 사용한 격리 미리보기

다음 수치는 v0.6.4를 기반으로 격리된 시험에서 발생 가중치를 조정해 촬영한 **선택용 미리보기**입니다. v0.6.5 배포본을 설치한 뒤 수행한 검증 결과가 아닙니다.

| 항목 | 원래 기준 | 50% 감소 미리보기 |
|---|---:|---:|
| 전체 야생 버섯 군락 자리 | 383 | 190 |
| 재배 가능한 11종 | 232 | 43 |
| 야생 전용 35종 | 151 | 147 |
| 실제 전체 개수 감소 | — | 약 50.4% |
| 재배 가능한 그룹의 실제 개수 비중 | 약 60.6% | 약 22.6% |

250×250 온대림에서 같은 지형·시드·시점·카메라로 비교했습니다. 표시를 위해 자연 생성된 버섯의 성장률만 100%로 바꾸고, 버섯을 수동 추가·삭제하지 않았습니다. 노란 원은 버섯 식물 한 자리의 표시이며 수확물 개수가 아닙니다. 이 한 지도 결과를 다른 생물군계·시드나 장기간의 공급량으로 일반화하지 않습니다.

## v0.6.5 설치본의 실제 초기 생성 검사

미리보기와 별도로 **설치본 14지도와 이전 가중치 대조 1지도**를 네이티브 지도 생성기로 검사했습니다. 설치본은 지원 6생물군계와 툰드라 대조에 각각 시드 A·B를 사용했습니다. 모든 지도는 250×250이며, 버섯을 수동 추가·삭제하거나 성장을 강제로 바꾸지 않은 최초 생성 상태를 집계했습니다. 이 실행에서는 사진을 새로 촬영하지 않았습니다.

| 생물군계 | 시드 A 전체 군락 | 시드 B 전체 군락 |
|---|---:|---:|
| 온대림 | 171 | 185 |
| 온대습지 | 164 | 175 |
| 아한대림 | 0 | 0 |
| 건조관목지 | 3 | 2 |
| 열대우림 | 59 | 66 |
| 열대습지 | 23 | 27 |
| 툰드라 대조 | 0 | 0 |

아한대림의 이번 시점 결과가 0이라는 사실만으로 다른 시점·계절에서도 버섯이 없다고 해석하지 않습니다. 두 시드의 초기 생성 결과는 지역별 일반적인 발생량이나 장기 공급량의 추정치가 아닙니다.

온대림 A에서는 현재 설치본에 **v0.6.4의 야생 가중치만 복원한 대조**를 한 번 더 생성했습니다. 전체 구버전 실행을 되돌린 시험은 아닙니다. 두 지도의 지형·지붕·눈 격자가 일치함을 확인했습니다.

| 항목 | v0.6.4 가중치 대조 | v0.6.5 설치본 |

| 전체 야생 버섯 군락 자리 | 374 | 171 |

| 발견한 종류 수 | 40 | 40 |

해당 조건의 전체 유효 가중치 잔존율은 약 50.00002%, 재배 가능 그룹의 유효 가중치 비중은 20%였습니다. 설치본 온대림 B는 재배 가능 40군락·야생 전용 145군락으로 총 185군락입니다. **선택용 미리보기 383 → 190과 이 설치본 대조 374 → 171은 서로 다른 실행 결과**이며 한 표본인 것처럼 섞지 않습니다.

## 검증 기록

정적 검사 **3,207개**, v0.6.4 보존·정책 대조 **730개**, Core + Harmony 영어 실제 실행·저장/불러오기·v0.6.1 시험 저장 복원 **7,232개**를 통과했습니다. 마이그레이션과 정의 생성의 반복 실행에서도 **295파일이 동일**했습니다. 생산 C# 소스 9개와 프로젝트·DLL, 기존 실행 자료의 허용 범위 외 값과 승인 그림, 이전 ZIP 36개를 보존했습니다.

위 네이티브 초기 생성 15지도 검사는 통과했으며, 새로운 실행 오류 없이 원래 시험 지도·정의를 복원했습니다. 시작 과정의 기존 Workshop 오류 1개와 비활성 RimTalk 경고 2개는 정확한 텍스트·스택·발생 횟수를 별도 보존했습니다. 결과 원본과 시작 진단은 [초기 생성 요약](TestResults/v0.6.5-native-density-summary.json)에 기록합니다.

120일 생태 모형·사용자 활성 79모드 조합·장시간 플레이는 이번 가중치 변경 뒤 새로 검사하지 않았습니다. 상세 증거와 중단 기록은 [검증 기록](VALIDATION.md)에 구분합니다. v0.6.4 검수는 [기존 QA 기록](QA-v0.6.4.md)에 보존하며, 이번 변경을 재검증한 결과로 인용하지 않습니다. 원래 제철·발광·균사 동작의 설명은 [v0.6.0 생태 문서](WILD-ECOLOGY-v0.6.0.md)를 참고하세요.
