# More Mushrooms v0.7.0 — 섭취·요리와 모드 설정

기존 독성 수확물 9종과 섭취 기능이 없던 약용·기타 10종을 일반 식재료로 사용할 수 있도록 바꿉니다. 독버섯은 먹을 수 있어도 기존 중독을 그대로 일으킵니다. 별도 약 제작이나 새 약효·맛 무드는 추가하지 않습니다.

## 섭취와 요리 대상

| 구분 | 대상 | v0.7.0 기본 동작 |
|---|---|---|
| 기존 식용 21종 | 일반 재배·고급 야생·특이 식용 | 기존 영양·맛 무드·섭취·요리 유지 |
| 기존 기타 식재료 2종 | 뽕나무버섯·노란뇌버섯 | 기존 영양·섭취·요리 유지, 새 맛 무드 없음 |
| 향정신성 4종 | 자유모자·주사위환각·광대·마귀광대 | 기존 일반 식재료 동작·환각·독성 유지 |
| 순수 독성 9종 | 알광대·독우산광대·붉은사슴뿔·노란각시·잭오랜턴·녹슨끈적·노란다발·화경·발광버섯 | 영양 0.05, 자동 섭취·일반 요리 허용, 중독 유지 |
| 약용 5종 | 영지·구름·상황·동충하초·차가 | 영양 0.05, 섭취·일반 요리 허용, 새 약효·맛 무드 없음 |

종의 수는 총 46종으로 유지합니다. 여기서 순수 독성은 향정신성 효과가 함께 있는 광대·마귀광대를 제외한 게임상 분류입니다. 향정신성 4종은 이번에 새로 식재료가 되는 종류가 아닙니다. 약용·기타 10종을 먹을 수 있게 하는 변경도 새 치료·숙주 감염·목재 부식 기능을 뜻하지 않습니다.

## 독버섯 모드 설정

두 설정은 독립적으로 켜고 끌 수 있으며 기본값은 모두 **OFF**입니다.

| 설정 | OFF | ON |
|---|---|---|
| 독버섯 자동 섭취 금지 | 다른 음식처럼 자동 섭취 후보가 될 수 있음 | 독성 9종 원물과 이 독버섯을 함유한 완성 음식·영양죽을 자동 섭취 후보에서 제외 |
| 독버섯 요리 재료 사용 금지 | 다른 재료처럼 요리 후보가 될 수 있음 | 독성 9종 원물과 이를 함유한 음식의 식사 제작 재료 선택·영양죽 투입을 제한 |

이 설정은 허용된 음식이나 재료에 추가 제한을 적용합니다. OFF로 바꾼다고 사용자가 음식 정책·요리 작업에서 직접 제외한 항목을 다시 허용하지 않습니다. 독성 9종에 대한 제한이며 향정신성 4종과 새로 먹게 된 약용·기타 10종의 동작은 구별합니다. 광대·마귀광대는 독성도 있지만 이번 두 토글의 제한 대상에는 추가하지 않습니다.

자동 섭취 금지는 지도에서의 자동 음식 선택과 캐러밴의 음식 선택에 적용합니다. **지도 우클릭의 직접 먹기와 소지품의 먹기 버튼은 사용할 수 있습니다.** 소지품 버튼은 기본 게임의 음식 정책·섭취 적합성 제한을 계속 따르며, 모드의 자동 선택 제한만 이 직접 명령에서 건너뜁니다. 이미 시작한 자동 섭취도 현재 설정과 대상 음식의 독버섯 포함 여부를 확인합니다.

자동 섭취 금지를 켠 상태에서 실제 호퍼에 대상 독버섯 원물이나 독성 음식이 남아 있으면, **깨끗한 재료가 함께 있어도 해당 영양죽 분배기 전체를 자동 음식 선택에서 제외**합니다. 요리 재료 사용 금지를 함께 켜 독재료가 투입 후보에서 빠진 상태에서도 이 보수적인 자동 제한을 유지합니다. 분배기를 다시 자동 이용하게 하려면 해당 재료를 호퍼에서 치우세요. 분배기 옆의 바닥에 놓였을 뿐 실제 호퍼에 들어 있지 않은 버섯은 이 검사에 포함하지 않습니다.

요리 재료 사용 금지는 이미 만든 독성 음식을 다른 음식의 재료나 영양죽 원료로 다시 쓰는 경우도 제한합니다. 영양죽 분배기는 허용된 다른 호퍼 재료가 있으면 그 재료를 사용하고, 깨끗한 재료만으로 충분한 양이 되는지 계산합니다. 기존 음식의 독성을 제거하거나 이미 기록된 사용량을 지우지는 않습니다. **설정을 켜기 전에 이미 재료 확보를 마친 진행 중 요리는 완료될 수 있습니다.**

## 기존 저장의 음식·요리 목록

기존 음식 정책과 요리 작업의 수동 선택은 변경하지 않습니다. 기존 저장에서는 새로 식용화한 독성 9종·약용/기타 10종이 요리 재료 목록에서 제외된 채 남을 수 있으므로, 원하는 종류를 직접 체크하거나 새 요리 작업을 만드세요. 새 게임과 새 요리 작업은 기본 음식 목록에 새 식재료를 포함하되, 모드 설정이나 작업 자체의 제한을 함께 따릅니다.

약용·기타 10종은 **수확물만** 식재료로 바꾸며 자연에서 자라는 식물을 직접 먹는 기능을 추가하지 않습니다. 기존 야생 식물의 섭취 여부·생태 필드는 유지합니다.

## 유지하는 내용

독버섯을 날것으로 먹거나 요리에 사용해 먹었을 때 기존 중독·치명 가능성·치료를 유지합니다. 원래 맛 무드와 향정신성 무드·통제 상실·내성, 야생 발생 50% 및 재배 가능/야생 전용 가중치 조정, 고리·균사·발광, 재배·수경·모둠 확률·성장·수확·가치·그림·Def ID와 packageId를 유지합니다.

## 검증과 배포

정적 검사 **3,211개**, v0.6.5 대비 허용 범위 외 보존 대조 **800개**를 통과했고, 정의 생성 반복 실행에서 **298파일이 동일**했습니다. Core + Harmony 영어 네이티브 실행은 **6,962개 통과**, 이 중 새 식용 설정 검사는 **502개**입니다. 두 설정의 네 조합과 저장/복원, 음식 정책·요리 필터 유지, 자동·직접 섭취, 기존 독성·환각과 식사 사용량 전달, 영양죽 제한·안전 호퍼 대체를 확인했습니다.

v0.6.5 시험 저장의 원본과 음식 정책 6개를 보존했습니다. 해당 원본에는 요리 작업이 없어서 기존 작업의 복원을 직접 시험하지는 않았고, 선택한 요리 작업·음식 정책의 저장/복원과 새 식용 19종의 마이그레이션 제외는 별도 사례에서 확인했습니다. 전체 사용자 모드 조합·렌더링한 설정 UI·장시간 플레이는 새로 검사하지 않았습니다. 중단 기록과 상세 한계는 [검증 기록](VALIDATION.md)에 적으며 이전 버전의 통과 수치는 이번 기능의 검증 결과로 사용하지 않습니다.

완료한 버전은 실행·소스 ZIP과 SHA-256을 `Releases/v0.7.0/`에 별도 보관하고, 게임 종료 후 이전 설치를 Mods 밖에 백업해 설치합니다. Steam 창작마당 업로드는 사용자가 진행합니다.
