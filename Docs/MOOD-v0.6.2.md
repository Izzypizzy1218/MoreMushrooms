# More Mushrooms v0.6.2 — 무드 설명과 근거

식용 버섯의 맛·식감을 짧은 1인칭 기억으로 적고, 향정신성 4종이 공유하는 환각 설명 3개도 같은 말투로 다듬었다. 식용 설명 9개와 환각 설명 3개를 한국어·영어로 변경했다. 꽃송이·자주방망이의 승인된 설명은 기준 문구로 유지했다. 최초 식용 10종의 설명은 이번 범위에 포함하지 않는다.

효과 이름, Def ID, 무드 수치, 지속시간, 통제 상실 시간, 성장·수확·가치, 독성·치료·생태와 그림은 v0.6.1 그대로다. 기존 저장의 기억을 새로 만들거나 나이·남은 시간을 바꾸지 않는다. 게임을 다시 실행해 새 정의를 로드하면 같은 기억에 새 설명이 표시된다. 약용·독성·소재 등 맛 무드가 없는 21종에 새 무드를 추가하지 않는다.

## 근거 적용의 범위

- 설명은 후기를 인용한 문장이 아니라 확인한 특징을 바탕으로 만든 게임용 창작 문구다. 양념·육수의 맛을 버섯 자체의 맛으로 옮기지 않았고, 랍스터버섯에 실제 바닷가재 맛이 난다고 적지 않았다.
- 포르치니·곰보는 종별 자료의 맛·살 기재를 사용했다. 모든 문구를 직접 시식 후기라고 주장하지 않는다. 블랙트럼펫은 정확한 C. cornucopioides 자료를 사용하며 미국 근연종의 향을 섞지 않았다.
- Cornell 후기의 판매용 대나무버섯은 정확 종이 확정되지 않았다. P. indusiatus의 동의어인 D. indusiata를 표기한 연구로 식감을 보조하되, 생시료·건조·조리 조건의 차이를 구분했다. 이것으로 Cornell 제품의 종을 확정하지 않는다.
- 자주방망이는 다른 종인 L. nuda의 향을 사용하지 않았다. 실로시빈 일반 자료·임상 경험은 자유모자와 주사위환각버섯 각각의 섭취 후기를 대신하지 않는다. 광대류 중독과 실로시빈 경험도 구분했다. 기존 공유 단계의 느낌을 표현하는 참고로만 사용했다.
