# More Mushrooms v0.6.4 — 실제 작업 경로 호환성 비교

검사일: 2026-10-11. 게임: RimWorld 1.6.4871 rev591.

Core 대조와 사용자 활성 모드 조합 모두 **기능 검사 42/42 PASS**, 실패 0이었다. 사용자 조합의 요청 모드 80개가 모두 로드됐으며 누락은 0개였다. 80개는 사용자 활성 목록 79개와 개발용 시험 하네스 1개를 합한 수다. DLC도 이 로드 수에 포함된다.

이 결과는 아래의 실제 수확·요리·식사·정책·스택 경로가 이번 조합에서 작동했다는 뜻이다. 모든 모드의 모든 기능에 오류가 없다는 보증은 아니다. 초기 번역 오류와 외부 자동 번역 서비스 제한은 아래에 별도로 남겼다.

## 실제 게임 작업 결과

하네스는 성숙한 재배 양송이에 실제 `Harvest` 작업을 주문했다. 요리는 `CookMealSimpleBulk`를 실제 `DoBill` 작업으로 세 번 수행했고, 만들어진 식사 중 한 개를 실제 `Ingest` 작업으로 먹였다. 단순히 생산 함수나 효과 함수를 직접 호출한 결과가 아니다.

수확량 11개는 기본 수확량 10과 실제 작업자 stat을 거친 결과다. 정의의 수확량을 11로 변경한 것이 아니다. 주사위환각의 두 예정 시간이 다른 것은 이번 회차의 추첨값이며, 둘 다 최초 표준 노출의 설정 범위인 6–8시간 안이다. 이 시험은 정신상태가 그 시간 동안 계속 유지되는지까지 관찰하지 않았다. 정상 수면·다운 등으로 더 일찍 끝날 수 있다.

준비 직후 기록된 온도는 Core 약 -1.08°C, 사용자 조합 약 19.35°C였다. 맵의 실외 온도 목표를 21°C로 바꿨지만 기존 온도 캐시와 즉시 동기화된 조건은 아니었다. 두 실행은 작업 완료와 결과의 기능 비교로 사용하며, 처리 시간·작업 효율·노동 손실의 대조 실험으로 해석하지 않는다.

## 정책·분할·중첩

두 실행에서 다음 검사가 모두 통과했다.

- 새 기본 요리 작업의 재료 필터가 자유모자·주사위환각·광대·마귀광대 원물 4종을 허용했다.
- 식사 정책에서 향정신성 식사 허용을 켜면 실제 `FoodPolicy.Allows`와 `Pawn.WillEat`가 해당 식사를 허용했다.
- 향정신성 식사 허용을 끄면 해당 식사는 거부하고 감자 식사는 계속 허용했다.
- 향정신성 식사와 일반 식사는 양방향 `CanStackWith`에서 중첩되지 않았다.
- 향정신성 식사를 실제 `SplitOff(1)`로 나눠도 두 스택의 식사당 원물 노출량이 1회로 유지됐다.
- 같은 노출량의 식사를 실제 `TryAbsorbStack`으로 합치면 원래 4개가 복원됐고 노출량이 증폭되지 않았다.
- 실제 섭취 시 원물 노출량이 중복 적용되지 않았으며, 주사위환각 기억과 송이 맛 기억이 각각 한 개 생성됐다.

## 선택한 native 메서드의 Harmony 소유자

아래는 실행 당시 Reflection으로 읽은 패치 메타데이터다. 이름은 Harmony owner ID이며, 발견 자체가 충돌의 증거는 아니다. 직접적인 함수 교체, 다른 진입점, 조회하지 않은 메서드까지 포함하는 전체 코드 감사는 아니다.

| 메서드 | Core 대조 | 사용자 조합 |
|---|---|---|
| `Thing.Ingested` | 조회된 owner 없음 | Prefix `OskarPotocki.VEF`, `rimworld.erdelf.alien_race.main`; Postfix `SimsTraitsMod`; Transpiler `rimworld.erdelf.alien_race.main`; Finalizer `OskarPotocki.VEF` |
| `GenRecipe.MakeRecipeProducts` | Postfix `izzypizzy.rimmushrooms.meal-exposure` | Postfix `com.alphabooks`, `SimsTraitsMod`, `com.vanillaanimalsexpandedroyal`, `izzypizzy.rimmushrooms.meal-exposure` |
| `WorkGiver_GrowerHarvest.HasJobOnCell` | 조회된 owner 없음 | Postfix `rimworld.erdelf.alien_race.main` |
| `Plant.PlantCollected` | 조회된 owner 없음 | Prefix `OskarPotocki.VEF`, `meathax.JobEffects`; Postfix `meathax.JobEffects` |

추가로 조회한 `Thing`/`ThingWithComps`의 `SplitOff`, `CanStackWith`, `TryAbsorbStack`, `WorkGiver_DoBill.JobOnThing`, `WorkGiver_GrowerHarvest.JobOnCell`, 두 `FoodUtility.WillEat` 오버로드와 세 `ThingFilter.Allows` 오버로드에서는 두 실행 모두 조회된 Harmony owner가 없었다. 이 목록에 없다는 이유만으로 관련 기능 전체가 무패치 상태라고 단정하지 않는다.

## 기능 검사와 분리한 실행 환경 문제

사용자 조합의 시작 로그에는 **영어 번역 관련 오류 211개**가 보고됐으며, **Auto Translation의 Google 요청에 HTTP 429 제한**이 기록됐다. 두 항목은 기능 검사 42/42 PASS와 별개인 조합/외부 서비스 문제다. 이 자료는 번역 오류가 모두 More Mushrooms에서 발생했다거나, 전체 조합에 오류가 없다고 판단하지 않는다.

이미 남은 실행 기록만 검토했다. 추가 Google 요청, 제한 우회 또는 개인 API 설정 복사는 하지 않았다. 외부 서비스가 필요한 모드의 인증·개인 설정·실제 서비스 기능은 이번 호환성 통과 범위에 포함되지 않는다.

## 남은 범위

이번 실제 작업 시험은 신선한 성인 인간, 기본 작물 수확, 기본 대량 간단한 식사, 주사위환각/감자/송이 재료에 한정된다. 외계 종족이 함께 로드됐어도 해당 종족 폰을 먹여 본 시험은 아니다.

다음 항목은 이 결과로 보장하지 않는다: 기존 사용자 저장의 작업 필터 이행, 저장/불러오기, 영양죽 분배기, 모드 전용 조리기와 기본 생산 경로를 우회하는 레시피, 자동 식사 탐색의 모든 상황, 의료/독성 장기 경과, 정신상태의 전체 지속 시간, 장기간 기억 감쇠, 전투, UI/이미지, 멀티플레이 및 전체 정착지 생산성. 예를 들어 All Memories Fade가 로드된 상태에서도 섭취 직후의 기억 값은 통과했지만, 이후 시간에 따른 감쇠는 이 시험에서 확인하지 않았다.
