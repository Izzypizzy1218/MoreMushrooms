# More Mushrooms v0.6.3 — 비유를 넣은 맛·환각 설명

사용자가 요청한 다양한 표현을 반영해 식용 21종과 향정신성 4종이 공유하는 환각 3단계의 한국어·영어 설명을 모두 수정했다. 반복되던 먹었다는 도입과 좋았다는 끝맺음을 줄이고, 종별 향·식감을 비유·의성어·개인 감상으로 표현했다. 효과 이름과 모든 게임 수치는 v0.6.2 그대로다.

## 자료와 비유의 구분

기존 2026-10-10 맛·향·식감 조사와 v0.6.2의 추가 자료를 바탕으로 표현만 새로 썼다. 위 링크는 그 조사에서 사용한 맛 자료이며 이번 문구 작업을 새 시식이나 별도의 실험 결과로 주장하지 않는다. 건강 효능과 치료 효과는 근거로 사용하지 않았다.

- 랍스터 한 점·국물 한 그릇·작은 스테이크는 식감이나 풍미에 대한 주민의 비유다. 랍스터버섯이 실제 해산물이거나 해산물의 맛과 성분이 같다는 뜻이 아니다.
- 먹물이 터지듯 번진다는 문장은 사용자가 요청한 이미지다. 섭취 시 실제로 먹물이 분출하는 기능이나 검은 액체 효과를 추가하지 않는다.
- 구름·실타래·비단·솔숲·박자·작은 나팔 역시 개인의 감상이다. 새로운 맛 성분·소리·상태 효과를 추가하지 않는다.
- 망태의 Cornell 조리 후기는 구매제품의 정확 종이 미확인인 한계를 유지하며, D. indusiata 연구의 식감은 보조 근거다. 자주방망이는 L. sordida 자료를 사용하고 L. nuda와 구분한다. 팽이·목이·느티만가닥 자료의 종·유통명 한계도 기존 조사와 같다.
- 실로시빈 일반 자료·임상 경험은 자유모자와 주사위환각 각각의 시식 후기로 간주하지 않는다. 광대류와 실로시빈을 같은 작용으로 설명하지 않으며 기존 공유 단계의 감상을 각색한 것이다.

원본 조사와 구체적인 열람 범위는 개발 소스의 `Research/SpeciesTraits/v0.1-2026-10-10/species-traits.json`, `Research/v0.6.2-premium-taste-notes.md`, `Research/v0.6.2-unusual-taste-notes.md`, `Research/v0.6.2-psychoactive-description-notes.md`, `Research/v0.6.2-retained-taste-anchors.md`에 보존한다. 최종 문구는 `Research/v0.6.3-final-descriptions.json`과 생성 XML을 대조한다.

## 유지한 게임 동작

송이·트러플·포르치니·곰보·블랙트럼펫은 +15/48시간, 나머지 식용 맛 무드는 기존 +3·+5·+7/6시간이다. 향정신성 무드·통제 상실·내성·공황도 그대로다. 성장·수확·가치·독성·치료·생태·그림·식사 기록·저장 ID와 기존 기억의 경과 시간을 변경하지 않는다. 맛·환각 무드가 없는 21종에 새 무드를 추가하지 않는다. 기존 저장은 새 정의를 로드하면 같은 기억에 새 설명이 표시된다.
