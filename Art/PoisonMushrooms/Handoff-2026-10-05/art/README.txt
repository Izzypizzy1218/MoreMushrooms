기준: Izzypizzy1218/MoreMushrooms v0.3.3, commit 82c5c1c.
기존 모드 그림과 실물 사진을 참고하여 built-in ImageGen으로 새로 제작한 그림입니다.

구성
- masters/: 생성 원본 25장 (종마다 식물 A/B + 상자 3단계)
- Textures/Things/Plant/RimMushrooms/: 256×256 투명 식물 그림 10장
- Textures/Things/Item/RimMushrooms/: 256×256 투명 상자 그림 15장
- preview.html: 인터넷 없이 열어보는 성장률·상자 수량 미리보기
- comparison.html: 성장률 10·50·100%와 상자 3단계 비교
- prompts/: 각 이미지의 최종 생성 프롬프트와 참조 경로 기록
- references/: 실물 사진과 저작자·라이선스·출처 기록
- manifest.json: 파일 해시·규격·투명도 검사 결과

성장 그림 사용법
A/B는 어린 버섯/성체의 차이가 아니라 성체 외형 변형 두 가지입니다.
기존 모드처럼 growth=g일 때 max(1, ceil(9*g))개를 배치하고,
각 그림의 평면 크기를 0.3+0.35*g칸으로 조절합니다.
10% = 1개 / 0.335칸, 50% = 5개 / 0.475칸, 100% = 9개 / 0.65칸.
미리보기의 배치는 이 규칙을 이용한 예시이며 게임 화면 캡처가 아닙니다.

상자 그림 사용법
01Low: 수량 1~25개
02Medium: 수량 26~50개
03Full: 수량 51~75개
그림 속 버섯 개수는 수량 구간을 나타내며 실제 스택 수와 일치하지 않습니다.

식물 그림은 기존 모드와 같은 작은 지상 군락 표현입니다.
화경버섯은 주간 모습이며 실제 발광 효과용 마스크는 포함하지 않았습니다.
이 묶음은 그림 제작 결과입니다. 식물/아이템 Def, 중독 효과, 등장 이벤트 등 게임 로직은 포함하지 않습니다.
실제 게임 적용과 인게임 검수는 별도 작업입니다.

사진 출처
references/sources.json에 원본 페이지·저작자·라이선스 링크를 기록했습니다.
Google Images는 검색 경로이며 각 사진의 출처는 Wikimedia Commons입니다.
사진을 재배포할 때 해당 사진의 라이선스와 저작자 표시를 유지하세요.

생성 방법
built-in ImageGen, transparent_background=true, 이미지별 개별 생성.
내보내기는 알파를 보존한 크기 조절 및 위치 정렬만 수행합니다.
식물: 불투명 영역 최대 가로/세로 192px, 중심 x=128, 하단 y=224.
상자: 불투명 영역 가로 226px, 중심 x=128, 하단 y=217.
