More Mushrooms — 추가 버섯 그림 작업 v0.1
작성일: 2026-10-09
기준 모드: v0.4.0 / 기존 구현 15종

작업 범위
기존 15종을 제외한 확장 후보 31종의 그림 초안이다.
종마다 수확물 상자 3장(01Low/02Medium/03Full), 성숙 성장 단위 2장(PlantA/PlantB)을 제작했다.
최종 게임용 PNG는 155장 = 상자 93장 + 성장 단위 62장이다.
이 폴더는 그림 작업 보관본이며, 추가 31종의 Def/효과/생성 규칙은 구현하지 않았다.
기존 소스와 설치 모드는 변경하지 않았다.

그림과 성장 표현
기존의 황토색 단일 벽면 상자, 우측 홈, 짙은 갈색 윤곽선, 단순한 색면을 참고했다.
실제 종의 사진은 형태 참고용으로 사용했다. 사진을 게임 텍스처로 붙이지 않았다.
모든 생성은 built-in image_gen으로 자산 한 장씩 수행했다. 투명 배경을 요청했다.
일부 원본에는 미세한 부드러운 음영이 있다. 256px 축소본에서 기존 스타일과 종별 특징을 시각 검수했다.
A/B는 서로 다른 성체 형태이며 '초기/후기 성장' 그림이 아니다.
기존 RimWorld 식물 표현에 맞춰 성장률이 높을수록 표시 크기와 반복 단위 수가 증가한다.
comparison.html의 25/50/75/100% 장면은 이 방식의 시뮬레이션이다. 게임 실행 화면이 아니다.
현재 단계에서는 어떤 후보에도 실제 발광·독성·식용·약효 동작을 새로 넣지 않았다.

사진과 후보명
실사 참고자료: 31종, 38장. 원본, 저자, 라이선스, 출처 URL, SHA256을 보존했다.
출처는 PHOTO-CREDITS.txt와 references/sources.json에서 확인한다.
species.json의 그룹은 사용자가 제시한 개발 분류이며 실제 식용 안전성을 보증하는 안내가 아니다.
이름이 포괄적인 후보는 그림 초안용 대표종을 기록했다:
- 실로시빈 추가종: Psilocybe cubensis (잠정)
- 발광버섯: Omphalotus nidiformis (잠정), 받침애주름 Mycena chlorophos와 구별
- 집버섯: Serpula lacrymans (잠정 게임명; 한국 문헌명 진황녹슨버짐버섯)
- 자주방망이: Collybia sordida (= Lepista sordida), 표준명 자주방망이버섯아재비
- 영지: Ganoderma sichuanense (= G. lingzhi), 유럽 G. lucidum과 구별
- 상황: Sanghuangporus sanghuang, 여러 종이 함께 있는 사진에서 C 패널만 참고
- 좀비개미 균류: Ophiocordyceps unilateralis s.l., 종복합체 범위를 유지
문어발은 악마손가락(Clathrus archeri)과 중복되는 후보로 별도 생성하지 않았다.
피흘리는 이빨은 사용자의 보류 목록에 따라 포함하지 않았다.

폴더 안내
masters/<ID>/ : 원본 생성 PNG. 후보마다 최종 5장.
Textures/Things/... : 기존 방식에 맞춰 정규화한 256×256 RGBA PNG.
prompts/<ID>.json : 실제 최종 생성 호출의 정확한 프롬프트·참조 경로·원본 경로.
prompts/records/ 및 교정 기록 : 개별 호출 기록과 교정 전 원본의 이력.
references/ : 실사 사진과 출처 기록.
reviews/ : 시각 검수 기록 및 축소본 전체 비교표.
comparison.html : 기존 15종과 추가 후보, 상자 단계, 성장률 미리보기.
manifest.json : 자산 수, 입력 출처, 크기·알파·해시 검사 결과.
baseline-preservation.json : 기존 모드 소스/이미지 108개 파일 보존 기준.

원본 보존과 내보내기
픽셀을 새로 그리지 않고 알파 경계에 맞춰 크기와 위치만 정규화했다.
식물: 긴 변192px, 중앙x128, 하단224px.
상자: 너비226px, 중앙x128, 하단217px.
build_assets.py는 정확한 5종류/31종/155장, 사진 출처, 프롬프트, RGBA, 투명 모서리, 해시를 검사한다.
이동한 보관본의 생성 기록에는 제작 당시 절대 경로가 남아 있다.
