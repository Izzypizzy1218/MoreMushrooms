# More Mushrooms — v0.5.0

림월드 1.6에 **버섯 46종**을 추가합니다. 기존 15종에 승인된 신규 31종을 모두 반영했습니다. **Core와 Harmony가 필요**하며 DLC는 필수가 아닙니다. 한국어와 영어를 지원합니다.

## 재배와 그림

기존 재배 버섯 9종에 **꽃송이버섯·자주방망이버섯아재비**를 추가해 총 11종을 재배 구역과 수경분지에서 기를 수 있습니다. 나머지는 야생 전용입니다. **모둠버섯은 기존 9종**을 같은 확률로 파종합니다.

모든 신규 종류에 성장 그림 A/B와 수확 상자 적음·중간·가득 그림을 연결했습니다. 성장률에 따라 기본 식물 렌더러가 그림의 크기와 배치 수를 바꾸며, 상자는 1~25개·26~50개·51~75개에서 바뀝니다. 기존 식용 10종의 수치·그림·맛 무드는 그대로 유지합니다. 강한 빛에서 성장하는 속도 감소와 야간 휴식도 유지합니다.

새 종류는 지정 생물군계의 기본 야생 식물 생성으로 드물게 발생합니다. **나무·그루터기·곤충 숙주·목재·최근 비에 따른 전용 발생 조건은 아직 구현하지 않았습니다.** 발광 계열의 실제 조명과 환경 피해도 이번 버전에 포함하지 않습니다.

## 향정신성 버섯

**자유모자·주사위환각버섯·광대·마귀광대**는 일반 식재료이며 원물이나 요리로 먹을 수 있습니다. 별도 추출물, 약 제작, 약물 정책은 없습니다. 새 조리 작업에서 자동으로 허용되며, 이전 저장의 기본 재료를 전부 허용하던 조리 작업도 한 번 갱신합니다. 재료를 골라 쓰던 작업은 유지합니다.

| 버섯 | 첫 표준 용량의 무드 | 통제 상실 |
|---|---:|---:|
| 자유모자·주사위환각버섯 | +15, 6시간 | 1~2시간 |
| 광대버섯 | +10, 6시간 | 2~3시간 |
| 마귀광대버섯 | +10, 6시간 | 3~4시간 |

표준 용량은 원물 10개입니다. 실제 먹은 양에 따라 무드와 통제 상실 시간이 줄어듭니다. 요리는 실제 투입량을 완성된 식사 수에 나누어 기록합니다. 향정신성 혼합 재료는 섭취 한 번당 합산해 처리하며, 가장 높은 기본 무드의 종류를 기준으로 합니다. 식사 분할·호환 스택 병합·저장/불러오기에도 사용량을 보존합니다. 향정신성 식사와 일반 식사, 용량이 다른 식사는 한 스택으로 합쳐지지 않습니다.

통제 상실 중에는 가까운 안전한 곳에서 배회하거나 멈춥니다. 공격·문 파괴·맵 이탈 행동은 추가하지 않습니다. 쓰러지거나 잠들면 배회를 끝내며 같은 노출로 다시 시작하지 않습니다. 기존 정신 상태를 덮어쓰지 않습니다. 반복 섭취는 공통 내성을 올려 무드 이득을 낮추고 불쾌한 환각 위험을 높입니다. 반복 노출의 통제 상실은 한 에피소드 최대 8시간입니다. 향정신성 무드는 4종끼리 중첩되지 않으며, 기존 식용 맛 무드는 별도로 유지합니다.

식사 정책과 저장 구역의 **‘향정신성 버섯이 든 식사 허용’**을 해제하면 해당 식사를 제외할 수 있습니다. 원물은 각 버섯 항목을 해제하세요. 이번 버전 전에 만들어져 실제 사용량이 없는 식사에는 새 노출량을 추정해 넣지 않습니다.

## 독성 버섯과 치료

**알광대·독우산광대·붉은사슴뿔·녹슨끈적**은 충분한 노출량에서 치료하지 않으면 사망할 수 있습니다. **광대·노란다발**은 누적 노출 3단위 이상의 고용량에서 치명형으로 전환됩니다. **마귀광대**는 심한 의식 저하·혼수까지 표현하며 기본 직접 사망 판정은 없습니다. 노란각시·잭오랜턴·화경·발광버섯은 위장 증상 위주로 기본 직접 사망 판정이 없습니다.

광대·마귀광대를 제외한 독성 수확물은 영양 0인 별도 원료이며 자동 식사와 일반 요리에서 제외합니다. 직접 섭취하거나 외부 모드가 재료로 사용하면 중독이 적용됩니다. 광대·마귀광대는 향정신성 효과와 중독이 함께 적용됩니다.

중독은 실제 노출량을 합산합니다. 일반 독버섯 원물 1개가 1단위이고, 향정신성 겸 독성인 광대·마귀광대는 10개가 1단위입니다. 기본 치명형의 최소 노출 기준은 0.25단위입니다. 모든 치명 판정은 **첫 증상 경고 뒤 최소 24게임시간**을 유예하며, 기본 의사·약품·침상과 반복 치료로 안정화할 수 있습니다. 6시간마다 치료 효과가 만료되고, 한 번의 치료로 위중한 중독을 완치하지 않습니다. 무약품·약초도 도움이 되며 치료 품질이 중요합니다. 다른 질병·부상까지 보호하는 규칙은 아닙니다.

## 약용·소재 버섯

**영지·구름·상황·동충하초·차가**와 기타 비식용 소재도 식물과 수확물로 추가했습니다. 약용 5종은 현재 야생 채집·저장·거래용이며 **약효·약 제작은 보류**했습니다. 개미동충하초의 숙주 감염, 집버섯의 건물 부식, 관상 버섯의 전용 효과도 아직 없습니다. 감정·미확인 버섯 시스템은 추가하지 않았습니다.
